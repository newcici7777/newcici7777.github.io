## 標籤頁

1. 使用标签页功能
打开新标签页：在Finder窗口中，按下 Command + T 或点击菜单栏的“文件” > “新建标签页”。

拖放窗口合并：如果你已经打开了多个Finder窗口，可以将一个窗口的标签页拖到另一个窗口的标签栏上，这样它们就会合并为一个窗口中的多个标签页。

2. 设置Finder默认以标签页打开
打开Finder设置：点击菜单栏的“Finder” > “设置”。

选择“在标签页中打开文件夹”：在“通用”标签中，将“首选以标签页方式打开文件夹”选项勾选。这样，新打开的文件夹会以标签页形式显示在当前窗口中，而不是新窗口。

3. 使用快捷键
合并窗口：如果你有多个Finder窗口，可以按下 Command + Option + W 关闭所有窗口，然后重新打开一个Finder窗口并使用标签页功能。


Mac 桌面出現幽靈般的截圖殘留（通常是縮圖無法點擊或永遠置於最上層），這通常是「訪達」(Finder) 或桌面視窗程序發生當機。請嘗試透過重新啟動系統程序來解決：方法 1：重新啟動「訪達」(Finder)按下鍵盤快捷鍵 Option + Command + Esc 打開「強制結束應用程式」視窗。在列表中點擊「訪達」(Finder)。點擊右下角的 「重新啟動」 按鈕。方法 2：透過「終端機」重啟桌面同時按下 Command + 空格鍵 打開 Spotlight 搜尋。輸入「終端機」並按下 Enter 打開。在終端機視窗中輸入以下指令，並按下 Enter：killall Dock此時桌面會短暫閃爍，殘留的圖示與視窗即會消失。若要避免未來再次發生，或不想讓截圖佔滿桌面：更改截圖儲存位置：按下 Shift + Command + 5 開啟螢幕截圖工具列，點擊「選項」，即可將截圖預設儲存路徑改為「文件」或「下載」等資料夾。如果這個問題反覆出現，您可以告訴我：您使用的是 哪一個 macOS 版本殘留的截圖是 檔案 icon 還是 預覽快照我將為您提供更進階的排解步驟！
