英文裡的 if 有兩種最常遇到的意思：
1. 如果（條件句）：
* If it rains tomorrow, I will stay home.（如果明天下雨，我就待在家。）

2. 是否（間接問句）：
* I don't know if he likes coffee.（我不知道他是否喜歡咖啡。）
- I want to know if the painting is good.（我想知道這幅畫好不好。）
- But I want to know if the painting is good.

可以跟 whether 互換

在「是否」這個意思上，if 跟 whether 是好兄弟，通常可以互相替換：
* I want to know whether the painting is good.（意思完全一樣）

## 現在進行式搭配條件句
 if 後面加上現在進行式（be + V-ing），就能完美表達那種「針對當下情境」
- if 現在進行式, 現在簡單式 (如果你正在做...的話,那就)
- If you're reading, turn on the light.（如果你正在讀書，就把燈打開）
  - 用現在進行式搭配條件句

- If you're working, I won't disturb you. （如果你正在工作，我就不打擾你了。）
- If you're watching TV, turn it down a little bit. （如果你正在看電視，把它轉小聲一點。）
- If you're eating, wash your hands first. （如果你正在吃東西，先去洗手。）
