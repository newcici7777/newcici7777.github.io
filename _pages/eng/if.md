英文裡的 if 有兩種最常遇到的意思：
1. 如果（條件句）：
* If it rains tomorrow, I will stay home.（如果明天下雨，我就待在家。）

2. 是否（間接問句）：
* I don't know if he likes coffee.（我不知道他是否喜歡咖啡。）
- I want to know if the painting is good.（我想知道這幅畫好不好。）
- But I want to know if the painting is good.

可以跟 whether 互換

在「是否」這個意思上，if 跟 whether 是好兄弟，通常可以互相替換：
* I want to know whether the painting is good.（意思完全一樣）
