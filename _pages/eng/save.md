save 常與 for 搭配，意思是「為誰保留」、「為了什麼東西而存錢」

## 保留
- Can you save a seat for me?（你可以幫我留個位子嗎？）
  - for 這邊是**替我／代勞**
- Save a piece of pie for me!（留一塊派給我！）

## save 拯救
- The vet tried to save the dying dog.（獸醫試著拯救那隻垂死「快要死掉」的狗。）
- save a life
- The emergency flight to the capital saved the patient's life. （那班飛往首都的緊急專機拯救了病人的性命。）
- Captain Jack saved the crew.（傑克船長拯救了船員）

## save 人 from something (拯救某人...免於、避開)
有時候 save 後面會接 from 或直接接抽象名詞，用來表示「免於、避開」：
- save someone from danger（把某人從危險中救出來）

## Save the day 拯救局面(拯救了這一天)
- You know she always saves the day in the end!你知道她最后总能挽救局面！
- In the end, the hero saved the day. 最后，英雄挽救了局面。
- I wonder which hero will save the day in the next movie!我想知道下一部电影里哪位英雄会力挽狂澜！
- Which hero will save the day?（哪位英雄會拯救危機？）

## save 存錢
- save money
- Do you have any tips on how to save money?你有沒有關於怎麼存錢的訣竅？
* *tips for saving money*（存錢的方法）
- He is **saving for** a new laptop.（他正在為買一台新筆電存錢。）

### saving**S**(名詞) 存款積蓄
savings,作為名詞要加S

- I used my **savings** to buy a laptop.*（我用我的**積蓄**買了一台筆電。）

## for saving（為了省錢 / 存錢）
作為動名詞，不用加S，因為是動作變名詞

- I put money in the bank for saving.（我把錢存進銀行。）


## save 節省時間、節省麻煩、節省力氣
- Can you imagine how much time this will save us? 你能想像這會為我們省下多少時間嗎？

```
save + [人] + [時間/金錢/麻煩]
```
- This app will save you a lot of time.（這個 App 會幫你省下很多時間。）
- Let's take a shortcut to save us some energy.（我們走捷徑來省點力氣吧。）
- This shortcut will save us ten minutes.
（這條捷徑會幫我們省下十分鐘。）
- Booking online will save us the trouble of waiting in line.（線上預訂可以省去我們排隊的麻煩。）

```
save + [時間/金錢/麻煩]
```
- save time（省時間）
- save money（省錢）
- save trouble（省去麻煩）

## save 存檔
- save a file
- Please save your progress before ending the gaming session.
（在結束遊戲時段之前，請先儲存你的進度。）
- The file didn't save properly, so I had to start again.檔案沒有存好，所以我被迫得從頭來過。
