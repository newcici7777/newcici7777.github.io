## more 代名詞 更多
- Can you tell me more? 跟我多講一點
- I want more.（我想要更多。）

### more 代名詞 + about 限定範圍(關於)
- I want to know more about you（我想多了解你一點。）
- Can you tell me more about this job?（你可以跟我多講一點關於這份工作的事嗎？）
- Can you tell me more about that story?(about 限定範圍)

## one more 再一個
原本已有的，再「多要」

one more 的後面非常百搭，只要直接加上「單數的可數名詞」，就能表達「再多要一個...」

* 因為核心的主體是 **`one`**（一個），`more` 在這裡是用來修飾 `one`，代表「額外的一個單位」。
* 所以後面的名詞必須維持**單數形**（如 *bottle*, *day*, *cup*），而不是複數。

```
one more + 可數名詞(不加s)
```
- one more! 再多要一個
- He stayed one more **year** in London to study English.（他在倫敦**多待了一年**學英文。）
- Can I have one more **beer**, please?可以再給我一杯啤酒嗎？(此處啤酒當可數名詞)
- Let's play one more **game**!我們再玩一場遊戲吧！
- Here's one more **bottle**.（這裡還有**一瓶**。／這裡多了一瓶。）
  - 原句: One more bottle is here.
- I need one more **day**.（我需要**再一天**。）
- Here's one more bottle.

```
大於1 + more + 容器單位(加s) + of + 不可數名詞(不用加s)
```
- Lin decides to eat one more slice of pizza.(再多吃一片)
- Lin decides to eat two more slice**s** of pizza.再多吃兩片
- The recipe requires two more spoon**s** of sugar.（這食譜需要**再兩湯匙**的糖。）
- I drank three more cup**s** of coffee.又多喝了三杯

```
大於1 + more + 可數名詞(加s)
```
- I need two more bottle**s**.（我需要**再兩瓶**。）
- Please give me five more day**s** to think about it.（請給我**再五天**的時間考慮。）
- Give me a few more minute**s**.（再給我**幾分鐘**。）
- Can you wait five more minute**s** for me?（你可以等我**再五分鐘**嗎？）
- I need two more minute**s** to finish this task.（我需要**再兩分鐘**完成這項任務。）
- We have three more chapter**s** to read before the exam.（考試前我們還有**三個章節**要讀。）
- There are ten more **people** waiting in line.（隊伍裡還有**十個人**在排隊。）
- We need six more chair**s** for the guests.（我們還需要**六張**椅子給客人。）


## `some` vs. `more`

- Some（一些）＝ 從「無」到「有」
  - I want some pizza.
  - Can I have some pizza?（可以給我一些披薩嗎？）
- More（更多）＝ 在「有」的基礎上「加碼」
  - I want more pizza.我想要更多披薩。 👉 潛台詞：我已經吃過了，但我還沒飽，繼續上菜！
  - Can I have more pizza?（可以再給我「多」一點披薩嗎？）

- some = 首次加入購物車（給我一點）。
- more = 追加數量（我還要更多）。

## more + 可數/不可數 名詞

```
more + 可數名詞(加s)
```
- Lin wants more slice**s** of pizza.Lin 想要更多片披薩
- We need more **people** to help us.我們需要更多人來幫忙。
- I have more question**s**.我還有更多問題想問。
- You should take more photo**s**.你應該多拍點照片。
- Do you want a single duck or more ducks **in** the photo?
- I don't need to turn for three more miles.

```
more + 不可數名詞(不加s)
```
- More water?再来一些水嗎
- More tea?再来一些茶吗
- I need more time.（我需要更多時間。） 
- Give me more time, please.請給我更多時間。
- I need more money.我需要更多錢。
- You need to drink more water.你需要多喝點水。
- more pizza.
- It will be more fun to make a pizza!
- More hot coffee or more water?再来一些咖啡还是再来一些水？
- Can you give me more food?


## more形容詞 + 比較長的形容詞
- The blue skirt is more expensive.
- This book is more interesting.

## more 副詞 + 副詞
- He is more careful.（他更小心了。）
- She speaks English more fluently.(（她說英文說得更流利。)

## 動詞 + more(副詞)
```
動詞 + 數量比較級 + (受詞/名詞)
```
不及物動詞，沒有受詞
- Earn more or spend less that is a question. 
  - 比較級（如 more 或 less）不是形容詞修飾名詞，而是當作副詞（Adverb），用來修飾前面的動詞，回答「賺（或花）得比以前／比別人多寡」的程度。
  - earn (動詞) + more (副詞比較級) = 賺得更多
  - spend (動詞) + less (副詞比較級) = 花得更少
- you want to talk more.
- We need to work more and talk less. （我们需要多做事、少說話。)

及物動詞，有受詞
- You should earn more money.（你應該賺更多錢。)
- He spends less time on video games.（他花更少的時間在電動上。）
- Eat more vegetables, and eat less junk food. （吃更多蔬菜，吃少一點垃圾食物。）
- Try to sleep more and worry less. （試著多睡一點、少擔憂一點。）


## 量詞片語(副詞) + more(形容詞) + 可數/不可數名詞
量詞片語a little/ a lot/ a few，這些是副詞，修飾的是「比較級形容詞more」，而不是「名詞」，所以名詞可以是可數或不可數。
- a little more  (再多一點)
- a little bit more  (再多一點點)
- a few more  (再多一些)
- a lot more  (再多更多) **沒有of**
- lots more (再多更多) **沒有of**
- much more (再多更多)
- many more (再多更多)

## much more + 可數/不可數名詞 表示「更多」
much 不只能修飾不可數名詞，它也可以用來修飾「比較級 (Comparative)」的形容詞。  
這時候，後面不管接可數名詞複數（如 bottles）還是不可數名詞（如 time），前面都可以用 much 來加強語氣。
- 不可數名詞：much more water（更多水）
- 可數名詞：much more plastic bottles（更多塑膠瓶）
- 不可數名詞: We need much more information before making a decision.（在做決定之前，我們需要更多得多的資訊。）

## much more(副詞) 修飾「形容詞、副詞或動詞」表示「...得多」
- This coffee is much more expensive than that one.（這杯咖啡比那一杯貴得多。）
- Learning a new language is much more challenging than I thought.（學一門新語言比我想像的具有挑戰性得多。）
- She is much more confident when speaking in public.（她在公眾發言時有自信多了。）
- His idea is much more practical for our team.（他的想法對我們團隊來說實用得多。）
- This movie is much more interesting than the previous one.（這部電影比上一部有趣得多。）
- Exercise makes me feel much more energetic.（運動讓我覺得充滿活力多了。）
- The new software is much more secure.（這款新軟體安全得多。）
- He worked much more carefully on this report.（他這份報告做得仔細多了。）
- Traveling by train is much more comfortable.（坐火車旅行舒適得多。）

## a lot more(形容詞) + 可數/不可數名詞 表示「多很多」
- But I need a lot more plastic bottles.
- I need **a lot more** water after running.（跑步後我需要**更多很多**的水。）
- She has **a lot more** experience than I do.（她比我有**豐富得多**的經驗。）
- We need **a lot more** time to fix this bug.（我們需要**多得多的**時間來修復這個臭蟲。）
- He earns **a lot more** money at his new job.（他在新工作賺的錢**多很多**。）
- There are **a lot more** options to choose from now.（現在有**多得多的**選擇可以挑。）
- We collected **a lot more** data for the project.（我們為這個專案收集了**多得多的**數據。）

## a lot more 修飾「形容詞、副詞或動詞」表示「多很多」
- This is a lot more difficult than I thought.（這比我想像的要難得多。）
- She works a lot more efficiently now.（她現在工作效率高很多。）
- This test is **a lot more** difficult than the last one.（這次考試比上次**難得多**。）
- I feel **a lot more** relaxed after taking a nap.（睡個午覺後我感覺**輕鬆多了**。）
- She speaks English **a lot more** fluently now.（她現在講英文**流利多了**。）
- This laptop runs **a lot more** smoothly than my old one.（這台筆電運作起來比我的舊筆電**順暢得多**。）

## a little more 修飾「形容詞、副詞或動詞」
當 more 當作副詞時，a little 可以用來修飾它，表示「程度稍微多一點」：
- I am a little more tired today than yesterday.（我今天比昨天稍微累了一點點。）
- Could you speak a little more slowly?（你能說得稍微慢一點嗎？）
