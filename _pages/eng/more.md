## more 代名詞 更多
- Can you tell me more? 跟我多講一點
- I want more.（我想要更多。）

### more 代名詞 + about 限定範圍(關於)
- I want to know more about you（我想多了解你一點。）
- Can you tell me more about this job?（你可以跟我多講一點關於這份工作的事嗎？）
- Can you tell me more about that story?(about 限定範圍)

## one more
原本已有的，再「多要」

one more 的後面非常百搭，只要直接加上「單數的可數名詞」，就能表達「再多要一個...」：
```
數字 + more + 單數的可數名詞
```
- one more! 再多要一個
- Lin decides to eat one more slice of pizza.(再多吃一片)
- Lin decides to eat two more slice**s** of pizza.再多吃兩片
- Can I have one more beer, please?可以再給我一杯啤酒嗎？
- I drank three more cups of coffee.又多喝了三杯
- Let's play one more game!我們再玩一場遊戲吧！

```
數字 + more + 不可數名詞
```
- one more minute.再多 1 分鐘
- Give me one more minute.再給我一分鐘 / 再等我一下。

## more + 單位s
- Lin decides to eat two more slice**s** of pizza.再多吃兩片

## more + 可數/不可數 名詞

- Some（一些）＝ 從「無」到「有」
  - I want some pizza.
  - Can I have some pizza?（可以給我一些披薩嗎？）
- More（更多）＝ 在「有」的基礎上「加碼」
  - I want more pizza.我想要更多披薩。 👉 潛台詞：我已經吃過了，但我還沒飽，繼續上菜！
  - Can I have more pizza?（可以再給我「多」一點披薩嗎？）

- some = 首次加入購物車（給我一點）。
- more = 追加數量（我還要更多）。

``
more + 複數可數名詞
```
- Lin wants more slices of pizza.Lin 想要更多片披薩
- We need more people to help us.我們需要更多人來幫忙。
- I have more questions.我還有更多問題想問。
- You should take more photos.你應該多拍點照片。

```
more + 不可數名詞
```
- Give me more time, please.請給我更多時間。
- I need more money.我需要更多錢。
- You need to drink more water.你需要多喝點水。
- more pizza.
