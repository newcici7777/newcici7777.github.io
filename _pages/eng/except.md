## except 位置
- 接在代名詞後面：
  - Everyone went except me.（除了我之外，大家都去了。）
- 接在名詞後面：
  - I like all sports except baseball.（除了棒球，我喜歡所有運動。）
- 放在句尾:
  - The store is open every day except Sunday.

## except(介系詞) 排除同類/不同類
- except: 排除同類型的東西
  - I like all subjects except math.（除了數學，我喜歡所有科目。）
- except for 放後面: 可排除同類/不同類型
  - I like all subjects except for math.（除了數學，我喜歡所有科目。）
  - Everyone left, except for the king.
- except for 放句首: 排除的類型不同
  - Except for the traffic, the trip was great.（除了交通之外，這次旅行很棒)
  - 交通跟旅行本身不是同類東西，一定要用 Except for

## 句型
```
[整體/全部] + except for + [例外]
```
- Everyone left, except for the king. 除了國王，大家都離開了
- Everyone left except for the king. 
  - 沒有逗號也是可以
- Except for the king, everyone left.
  - Except for 放句首
