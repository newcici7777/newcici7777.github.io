## long(形容詞) 久
- Summer is long.

## 問每一次...多久？ How long ... each time?
each time（每一次，副詞，修飾動詞)
```
How long 助動詞 + 主詞 + 動作 + each time?
```
- How long do you study each time?（你每次都讀多久？）
- How long did you study yesterday?你昨天学习了多久？
- How long did Tom live in Oxford?汤姆在牛津住了多久？

### for + 時間（表達持續多久
```
for + 時間 + each time 
```
在英文中，介係詞 for 後面加上一段時間，是用來表示某個動作「持續了多久」。

- I study for [時間] each time. （我每次讀...）
- I study for one hour each time
- I study (for) one hour.(也可省略for跟each time，因為問句已經有each time)

### 時間 + a day 
```
時間 + a day 
```
這裡的 a（或 an）在文法上除了當作「一個」之外，在計量、頻率的用法裡，它解釋為「每（per）」的意思。
所以 a day 就是「每一天」

通常我們會把「做某事多久（時間）」放在前面，後面直接加上「a + 時間單位」：
- one hour a day（一天一小時）
- 8 hours a night（一晚睡8小時）

根據問句How long do you study each time?

可回答:
- About [時間] a day. （大概一天...）
- I study (for) one hour a day.（我一天讀書一小時。）

## 次數 vs 時數
- Five times a week = 一週五次（Time 當「次數」，可數）
- One hour a day = 一天一小時（Hour 當「時間單位」，可數）

## How long + be動詞 「狀態」持續多久
```
How long + be 動詞 + 主詞 ...?
```
- How long is the movie? (這部電影有多長／多久？)
- How long were you there? (你在那裡待了多久？)

## How long + 過去式
時間在過去就結束，沒有延續到「現在」。
- How long did you go camping at the park?（你們去公園露營去了多久？）
- How long did you work for that company?(你為那家公司做了多久)

## How long + 現在完成式（詢問持續到現在的動作）
如果你想問某個狀態從過去一直延續到現在多久了，句型是：
```
How long + have/has + 主詞 + 過去分詞 (V-pp) ...?
```
- How long have you lived here? (你住在這裡多久了？)
- How long has she worked at this company? (她在這家公司工作多久了？)

### For + 一段時間 （持續了多久）
```
For + 一段時間
```
- 問： How long have you lived here? (你在這裡住多久了？)
- 答： For three years. (三年了。)
- 答： I have lived here for five years.

### Since 年/子句 (自從...)
```
Since + 年
Since + 主詞 + 過去簡單式 ...
```
- 問： How long have you studied English? (你學英文學多久了？)
- 答： Since 2024. (自從 2024 年開始。)
- 答： Since I was a kid. (自從我小時候開始。)

## How long + 過去式（詢問「過去」某個持續的動作）
- 問： How long did you stay in Japan? (你在日本待了多久？)
- 答： I stayed there for three days.

### For + 一段時間 （持續了多久）
```
For + 一段時間
```
- 問： How long did you wait? (你等了多久？)
- 答： For twenty minutes. (二十分鐘。)

## How long 實體物件的長度有多長？
用來量測實體東西的長度（例如距離、尺寸）
```
How long + be 動詞 + [實體名詞] ...?
```
- How long is this bridge? (這座橋有多長？)
- How long is your hair? (你的頭髮有多長？)

回答:
```
數字 ＋ 單位
```
- 問： How long is this table? (這張桌子有多長？)
- 答： Two meters. (兩公尺。)
- 問： How long is the movie? (這部電影有多長？)
- 答： Two hours. (兩小時。)

## How long does it takes to 原形動詞 (花多久時間)
詢問一件事情「花了多少時間」，或是從 A 點到 B 點「耗時多久」。
如果是問「做某個動作需要花費多少時間」，可以用 It takes 來回答：
```
How long does it take to ....?
```
- 問： How long does it take to get there? (去那裡要花多久時間？)
- 答： It takes about 30 minutes. (大約花 30 分鐘。)

- How long does it take to get to the hotel?（去飯店要花多久時間？）
  - It takes about 10 minutes.（大話要花大約 10 分鐘。）
