這句話裡的 **`got`**（`get` 的過去式），核心意思是「接受、進行（檢查/治療）」**或**「拿到（照完的 X 光片）」！

在日常英文和醫療溝通中，**`get`** 是個超級萬能又道地的動詞。我們從以下兩個層面來拆解為什麼這裡會用 **`get`**：

---

### 一、 為什麼用 `get`？（醫療與日常的核心邏輯）

#### 1. 表示「接受 / 進行（某項檢查或醫療處置）」

在英文裡，當病人去「照 X 光、抽血、做掃描、打疫苗」時，我們不是用 *make* 或 *do*，而是最習慣用 **`get`**！
因為這代表你「接受了這項服務/處置，使自己獲得了這個檢查結果」。

* **get an X-ray** $\rightarrow$ 照 X 光 / 接受 X 光檢查
* **get a blood test** $\rightarrow$ 做抽血檢查
* **get a flu shot** $\rightarrow$ 打流感疫苗
* **get a check-up** $\rightarrow$ 做健康檢查

#### 2. 表示「拿到 / 取得（X 光片/檢查報告）」

`get` 本身最基礎的意思就是「獲得/拿到」。所以 **`got an X-ray`** 在畫面上也可以理解為：在見醫生之前，Lisa 已經「拿到/拍好了那張 X 光片」。

---

### 二、 這句話的完整意思與情境

> **"Lisa got an X-ray before the doctor..."**
> （Lisa 在看醫生之前，先**照了 X 光** / **做了 X 光檢查**……）

完整句子的後半段通常會接醫生做了什麼，例如：

* *Lisa got an X-ray before the doctor **examined her**.*
（在醫生為她檢查之前，Lisa 先照了 X 光。）
* *Lisa got an X-ray before the doctor **came in**.*
（在醫生進來診間之前，Lisa 就已經照好 X 光了。）

---

### 💡 延伸：`get` 在醫療情境的三大超高頻搭配

把這個 `get` 的邏輯記起來，以後看診或描述生病/檢查時會非常順手：

| 句型結構 | 中文意思 | 實用例句 |
| --- | --- | --- |
| **get + 醫療檢查/處置** | **進行/接受（檢查/疫苗）** | *I need to **get an X-ray** for my leg.*<br><br>（我的腳需要去**照個 X 光**。） |
| **get + 疾病/症狀** | **得病 / 染上（症狀）** | *She **got a cold** yesterday.*<br><br>（她昨天**感冒了**。）<br><br>*I **got a fever**.*（我**發燒了**。） |
| **get + 治療/處方** | **取得（藥物/處方）** | *He **got a prescription** from the doctor.*<br><br>（他從醫生那裡**拿到了處方箋**。） |

---

### 🎬 總結小筆記

英文說「照 X 光」，最道地、最自然的講法就是 **`get an X-ray`**（或是 **`have an X-ray`** / **`take an X-ray`**），而不是用 *do* 或 *make* 喔！

這樣連結到 `get` 代表「接受處置 / 取得結果」的底層邏輯，是不是就很好理解了呢？
