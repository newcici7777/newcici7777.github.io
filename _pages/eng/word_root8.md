## ag / ig / am 做、衡量
ag / ig / am (字根) = to drive / to weigh（做、推動、秤重、衡量）  
ag,ig,am 是「天平的指針」，是用來「精準稱重、把好的壞的分清楚」  
子音相似互換 : a**g** -> a**c**

|單字|字根|詳解|
|:-------|:--------------|:----------------------------|
|Act|Ac (做)ct(做) |行為|
|Practice|prac(做)+ tice (名詞/動詞尾)|練習|
|Examination|ex(出來）+ am(天平來衡量)|天平的指針是用來「精準稱重」演變到學校或職場，用來衡量、秤秤看學生到底有多少實力的行為|
|managerial|man(手)+ ag(做→管理)+ er (人) + ial(形容詞)|用手把事情理順、掌控局面，這就是管理、經營managerial skills 管理技巧、managerial position 管理職）|
|Agent|ag (做、推動) + ent (人)|幫你出面去推動事情、做事情的人 → 代理人、經紀人、特務|
|Agenda|ag (做) + enda (複數名詞尾)|今天開會必須去推動、去做的所有事情 → 議程、待辦事項|
|Agile|ag (動) + ile (易於...)|身體或腦袋非常容易動起來的 → 敏捷的、靈活的（如軟體業的「敏捷開發」）|
|Ambiguous|ambi- (雙向) + ig (推動) + ous|兩邊都可以推得通、模稜兩可的 → 含糊不清的、有歧義的|

## journ 白天的、每日的
每天清晨太陽升起時，一邊喝咖啡，一邊翻開今天剛送達、油墨未乾的『日報』

- journ (字根) = day（一天、每日）
- Journal (名詞)： journ（一天）+ al（名詞尾）
  - 最早指的是「每日的記錄」。演變到今天，變成了你每天寫的日記，或是定期出版的期刊、雜誌、日報。
- Journalist (名詞)： journal（定期刊物）+ ist（專業人士） 
  - 專門為這些刊物跑新聞、寫報導的人，也就是記者。
- Journalism (名詞)： journal + ism（行業、學門） 
  - 記者的這份集體志業，引申為新聞業、新聞學。
- Journey(句詞): journ (一天) + ey
  - 古代指「走一天的路程」 → 旅行、旅程

## ambi

- Ambition ambi- (周圍) + it (走) + ion
  - 為了拉選票而在城裡「四處走動」的強烈渴望 → 雄心、抱負、野心
- Ambiguous ambi- (雙向) + ig (推動) + ous
  - 兩邊都可以推得通、模稜兩可的 → 含糊不清的、有歧義的
