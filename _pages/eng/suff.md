## ment 名詞
動詞 + ment = 名詞  

### ment是一個把動詞打包成「實體物品、制度、工具」的名詞字尾。  
- Docu（教導/記錄字根） → Document（文件，名詞）
- Frag-（打破字根） → Fragment（碎片，名詞）
- Comple-（完成/填充字根） → Complement（互補物，名詞）
- Compli（讚美） → Compliment（稱讚，名詞）

### 動作的【工具、手段】或【完成後的具體狀態、結果】
ment「一整套工具或具體成果」（如「付款、設備、管理」）的動詞
- pay（付款） → payment（款項 → 付款後的具體結果）
- move（移動） → movement（移動 → 移動的具體狀態/運動）
- develop（發展） → development（發展）
- govern（統治） → government（政府 → 統治國家的具體工具/機構）

## tion 名詞
### tion 把動作，變成「一件事情或行為」
「動詞」字尾t + ion = 名詞
- Act（行動，動詞） + ion → Action（行動、行為，名詞）。
- Create（創造，動詞） + ion → Creation（創造、創造物）。
- Invent（發明） → Invention（發明、創造）
- Connect（連結） → Connection（關聯、連接）
- Prevent（預防） → Prevention（預防、阻止）
- Educate（教育，動詞） + ion → Education（教育）。

### tion 抽象狀態與溝通
「動詞」字尾t + ion = 名詞
- Negotiate（談判） + ion → Negotiation（談判、協商）。
- Produce（生產） + tion → Production（生產、產量）。
- Compete（競爭） + tion → Competition（競爭、比賽）。
- Promote（晉升/促銷） + tion → Promotion（升遷、促銷活動）。

### tion 場所、機構或組織
動詞 + tion = 名詞  
- State（站立/駐紮） + ion → Station（車站、局、駐點 → 讓火車或警察固定站立停駐的地方）。
- Associate（合夥/關聯） + ion → Association（協會、聯盟 → 把大家關聯在一起的組織）。
- Found（建立/打地基） + tion → Foundation（基金會、地基）。

### tion 重音
重音落在 -tion 的「前一個音節」！
- Inform（通知，重音在 form） → Information（訊息，重音被吸到 ma 身上）。
- Introduce（介紹，重音在最前） → Introduction（介紹，重音被吸到 duc 身上）。
- Communicate（溝通，重音在 mu） → Communication（溝通，重音被吸到 ca 身上）。

### ate + ion = ation
-ate 結尾的動詞 → 去掉 e 變成 -ation：
- create（創造） → creation
- educate（教育） → education

### ct/pt + ion = tion
-ct / -pt 結尾的動詞 → 直接銲上 -ion（因為有 t 了，直接防撞）：
- act（行動） → action
- direct（指導） → direction
- adopt（採用） → adoption

## sion 名詞
結尾為d或s + sion
- Decide（決定） → Decision（決定，名詞）。

例外:
- Permit（允許） → Permission（允許/許可證，名詞）。

## true 名詞
藝術、建築、手工藝相關的詞彙
### true 動作留下來的「實體結果」
- mix混合 →  Mixture 
  - 混在一起之後產生的東西 → 混合物、混合狀態
- sign記號 →  Signature 
  - 簽完名後留在紙上的那個記號 → 簽名
- create創造 →  Creature 
  - 被上帝創造出來的成果 → 生物、造物、動物
- fract破裂 →  Fracture 
  - 骨頭或物體被折斷後的那個裂縫 → 骨折、裂縫

### true 結果,過程,形狀
- fail (失敗) →  Failure 
  - 事情搞砸了的那個「結果」 → 失敗、故障
- depart (出發/離開) →  Departure 
  - 飛機或人離開的那個「動作/過程」 → 出發、離境
    
### true 建築
- struct (建造) →  Structure  
  - 一步步建造起來的那個結構 → 結構、建築物
- architect (建築師) →  Architecture 
  - 建築師所做的這門專業與藝術 → 建築學、建築風格

### 結合特定的知識、行業或文化
- cult (耕作/照顧) →  Culture 
  - 對心靈與土地的深耕與照料 → 文化、教養
- agri (田地) + cult (耕作) →  Agriculture 
  - 在田地上耕作的技術與行業 → 農業

## sure 內心感受、測量、核心狀態
動詞的字尾 d 或 s ，為了發音順暢，改成sure
- please (使高興) → Pleasure 
  - 內心感到高興與滿足的狀態 → 愉快、榮幸、樂趣
- mensus (測量) → Measure 
  - 把東西的分量抓出來的過程 → 測量、計量 / 措施
- press (按壓) → Pressure 
  - 被狠狠往下壓、喘不過氣的狀態 → 壓力
- close (關閉) → Closure 
  - 一件事情被關上、畫下句點的狀態 → 結束、倒閉 /（心靈的）釋懷
- expose (暴露) → Exposure 
  - 被完全打開、暴露在外的狀態 → 暴露、曝光率

## ty/ity 抽象名詞
### ty 名詞 形容詞字尾是e
形容詞字尾是e + ty = 名詞 形容詞意思的「抽象名詞」
- Safe（安全的） + ty → Safety（安全、安全性）。
- Pure（純淨的） + ity（e 變成 i） → Purity（純淨、純潔）。

例外:
- Simp-（簡單的） + icity（變體） → Simplicity（簡單、樸素）。

### ty 名詞 某種能力、營運指標或商品特質
形容詞字尾able/ive/al/l + ty/ity = 形容詞意思的「抽象名詞」  
- Cruel（殘忍的） + ty → Cruelty（殘忍、殘酷行為）。
- Able（有能力的） + ity = Ability（能力）。
- Productive（有生產力的） + ity = Productivity（生產力、生產率 ）。
- Creative（有創造力的） + ity = Creativity（創造力）。
- Flexible（有彈性的） + ity = Flexibility（彈性、靈活性 → 如：上班時間的彈性）。
- Quality（品質）qual + ity
- Quantity（數量）
- Availability（可利用性/空位)
- Possible → Possibility（可能性）
- Formal → Formality（正式手續）。

### ty 一整群人或一個整體（集合名詞）
具備某種特質的人事物「打包成一個群體」
- Soc-（同伴/社會） + iety 
  - Society（社會、協會 → 同伴們聚集在一起的整體）。
- Commun-（共同的） + ity 
  - Community（社區、共同體 → 擁有共同生活特質的一群人）。
- Author（權威/原創者） + ity 
  - Authority（權威、官方當局 → 具備說話分量的人或政府機構）。

### ity 重音音節
重音在倒數第三個音節 
- Active → Ac`tivity（共 4 音節，倒數第三是 ti）
- Possible → Possi`bility（共 5 音節，倒數第三是 bi）

## 字尾t + ive(形) + ate(動詞) = 動詞 
把形容詞變成動詞，動詞是形容詞的「動態」意思
- act(n.行為) ac(做)+ ct(做) → active(adj.活躍的) → activ(去掉e) + ate (v.啟動; 觸發；使活化) 

| 單字 | 字根 | 意義 |
|------|------|------|
| cultivate | cul（耕作）+ tivate | 耕種、培養 |
| activate | activ（活躍的）+ ate | 激活、啟動 |
| motivate | mot（移動）+ ivate | 激發、促使 |
| captivate | capt（抓住）+ ivate | 迷住、吸引 |
| festive | fest（節日）+ ivate | 慶祝（較少用） |

## 字尾d 變 t 名詞
動作（動詞，聲帶震動 d）→ 結果/狀態（名詞，聲帶熄火 t）
- extend (動：延伸) → + -t → extent (名：程度/範圍)
- intend (動：打算) → + -t → intent (名：意圖)
- ascend (動：上升) → + -t → ascent (名：上升)
- descend(動詞：下降、走下去 → 來自 de- 向下 + climb 爬) + -t → descent 名詞（下降/血統）
- Bend (彎曲) → Bent (傾向/愛好)
- Lend (借出) → Loan / Lent (借出物/借期)

## it 走 (名詞)
it 放在單字尾巴時，通常代表一個「走、去、移動」的動作或結果
### 交通、移動、查看
前面動詞+it 多半跟交通、移動、查看有關（如 往外走是 exit，跨過去是 transit，繞圈走是 circuit！）。

- Exit ex- (向外) + it (走)
  - 讓人可以「往外走」的地方 → 出口、離場
- Transit trans- (跨越) + it (走)
  - 從這區「走過去」另一區 → 過境、運輸、轉機
- Visit vis- (看) + it (走/去)
  - 為了看某人而「走過去」 → 拜訪、參觀
- Circuit circu- (圓圈) + it (走)
  - cu念c，u不發音
  - 圍繞著圓圈「走一圈」的路線 → 電路、巡迴、環形路線
- Audit aud- (聽) + it (走/去)
  - 古代官員「走過去旁聽」帳目匯報 → 審計、稽核、旁聽
- Inhabit in- (在裡面) + hab- (居住) + it
  - 走進去一個地方並在裡面定居 → 居住於、棲息
- Initial in- (進入) + it (走) + ial
  - 剛剛「走進去」的那個最起點 → 最初的、開始的 / 名字的首字母
- Ambition ambi- (四周) + it (走) + ion
  - 為了拉選票而在城裡「四處走動」的強烈渴望 → 雄心、抱負、野心


### it被動的狀態(ed→ it) 
名詞+it(狀態/東西)   特別留意商務財務情境，它很常是跟錢、信用、審查有關的專業術語
- Credit：cred（相信）+ it 
  - **被信任**的狀態 → 信用、貸款、讚譽。
- deposit（存錢、留下、押金）de-（向下）+ pos 放置 + it
  - 錢放下，留下東西 → （存錢、留下、押金）
- Deficit：de-（向下/缺乏）+ fac/fic（做）的變形 + it 
  - 做出來的錢往下掉、不夠的狀態 → 赤字、虧損

### it小一號、精緻的東西
- Rabbit：兔子的古稱，自帶一種毛茸茸、小巧可愛的語感。
- Exhibit：ex-（向外）+ hib（拿/握住）+ it  
  - 拿出來放在外面的「小展品」，引申為展覽、陳列品。

## itiner 走
「旅行、路程」的主格叫：iter（走的路），但當它變成「去旅行的...」的時候，身體中間就會被撐開，變成：it**in**er

因為這個字根代表「長途跋涉地走」，所以它生出來的單字都帶著「四處奔波、居無定所」的流浪感：

- itinerary
  - itiner（漫長旅程）+ ary（與...有關的事物） → 行程、旅程計畫表。
- Itinerant
  - itiner（長途奔波）+ ant（人，名詞或形容詞字尾） → 形容詞指「巡迴的、流浪的」；名詞指「巡迴工作者」。
  - 例： itinerant musicians（巡迴演出的流浪樂手）、itinerant workers（四處打零工的流浪勞工）。
- Itinerate
  - itiner（走）+ ate（動詞字尾） → 動詞：巡迴、四處旅行（特別指法官巡迴審判，或傳教士四處傳教）。

- A detailed itinerary：一份詳細的行程表。
- Flight itinerary：航班行程表 / 電子機票行程單（通常包含航班號碼、起飛與抵達時間）。
- Change the itinerary：變更行程。


## ite 
ite 是ed，被動式，「被...的」「具有...性質的」

### ite 抽象的形容詞
抽象字根 + ite = 形容詞

- Opposite (形容詞/名詞)： op- (反方向) + pos (放置) + -ite 
  - 「被」放在反方向的 → 相反的、對立的
- Definite：de- (向下/明確) + fin (界線) + ite 
  - Define 動詞，是「去劃定界線、去定義」
  - 「界線被劃得很清楚的」 → 引申為「明確的、肯定的」（形容詞）
- Finite[ˈfaɪnaɪt] (adj. 有限的、有盡頭的)
  - 拆解： fin- (範圍、結束、做完) + -ite (形容詞：…的狀態)
  - 意思： 事情已經被「做好邊界、劃下句點」了，所以是有限的。
- Infinite：in- (否定) + fin (界線) + ite 
  - 沒有界線的 → 無限的、無窮的。
  -（in- 是「不」，界線無法「被」劃定的）
- Polite：pol (擦亮/平滑) + ite 
  - 行為舉止像「被」擦拭得亮晶晶一樣 → 有禮貌的。
- unite: un(統合成一個) + ite 「被」統一。(形容詞/動詞)
- Deficit (n. 赤字、虧損 / 沒做好)
  - 拆解： de- (向下、減少) + fic- (做) + -it/ite (名詞/形容詞字尾)
  - 意思： 字面意思是「事情沒有做夠、往下做、沒做好」，引申為錢不夠、赤字。

### ite 名詞 人或物
- Favorite：favor (喜愛) + ite → 「被」偏愛的那個人 → 最喜愛的人或物。
- Elite：選出來（elect）的優秀人群 → 菁英、優秀分子。
- Socialite：social (社交) + ite → 活躍於社交圈的人 → 名媛、社交名流。
- Appetite [ˈæpəˌtaɪt] (n. 食慾、胃口) 
  - 拆解： ad- (朝向) + pet- (追求、尋找) + -ite
  - 意思： 本能地去追求食物，直到「被」滿足為止。

## age 名詞
動詞 + age = 動作的過程、結果
名詞 + age = 費用/集合名詞/狀態  

### age總稱/集合名詞
- Bag（袋子） + age → Baggage（行李 → 所有的袋子、箱子打包在一起的總稱）。
- Pack（打包） + age → Package（包裹、整套方案 → 包在一起的一坨東西）。
- Garbage（垃圾） / Luggage（行李） 也是同樣的打包邏輯。

「打包」起來的總數
- Percent（百分比，名詞） + -age → Percentage（百分比/比例）。
- Mile（英里，名詞） + -age → Mileage（里程數 → 一英里一英里「累積打包」起來的總數）。

### age 動詞動作發生的「過程、結果或場所」
代表做完某個動作後，所留下來的狀態、結果或做這件事的地點：
- Marry（結婚） + age → Marriage（婚姻 → 結婚之後的長久狀態）。
- Break（打破） + age → Breakage（破損、破損量 → 打破東西後的結果/數量）。
- Pass（通過） + age → Passage（通道、走廊、文章段落 → 讓人或文字通過的地方）。
- Store（儲存） + age → Storage（儲藏、儲存空間）。
- Wreck（毀壞，動詞） + -age → Wreckage（殘骸 → 毀壞後「打包」留下來的廢墟垃圾）。
- Drain（排水，動詞） + -age → Drainage（排水系統/排水量 → 排水這個動作的整體運作）。
- Leak（漏，動詞） + -age → Leakage（洩漏、漏出量 → 漏出來的那個狀態或東西）。
- Pack（打包，動詞） + -age → Package（包裹 → 打包好的那個實體物品）。
- Damage（損害)

### age 做完某事要付的「費用」
- Post（郵寄） + age → Postage（郵資 → 郵寄信件要付的費用）。
- Port（港口） + age → Portage（搬運費、水運運費 → 貨物過港要付的錢）。
- Store（儲存，動詞） + -age → Storage（儲藏/倉儲費 → 儲存空間或其費用）。

### age身分、地位、狀態
- Short（短缺的） + age → Shortage（短缺、不足的狀態）。
- Bond（連結/綁定） + age → Bondage（束縛、奴役狀態 → 被綁死死的狀態）。
- Host（主人） + age → Hostage（人質 → 古代住在人家家裡作為「擔保身分」的人，後來演變成被綁架的人質）。

## hood 名詞
### hood代表生命的「某個特定時期、身分或狀態」
- Child（兒童） + hood → Childhood（童年 → 當兒童的那段黃金時期）。
- Mother（母親） + hood → Motherhood（母性、母親的身分 → 身為媽媽的狀態與職責）。
- Adult（成人） + hood → Adulthood（成年期）。

### hood住在同一個區域、或擁有共同特質的群體
- Neighbor（鄰居） + hood → Neighborhood（社區、鄰里 → 鄰居們共同生活、被罩在同一個生活圈的區域）。
- Brother（兄弟） + hood → Brotherhood（手足之情、兄弟會 → 擁有共同信念、像親兄弟一樣團結的群體）。

## ship 名詞
這艘船上載著雙方的感情

### ship 人與人之間的「互動與關係」
- Friend（朋友） + ship → Friendship（友誼 → 朋友之間共同維繫的關係船）。
- Relation（關係） + ship → Relationship（戀愛/人際關係 → 專指兩個人之間深度的情感連結）。
- Partner（夥伴） + ship → Partnership（合夥關係、夥伴關係）。

### ship 法律、組織給予的「身分與資格」
- Member（會員） + ship → Membership（會員資格 → 讓你能待在會員這艘船上的權利）。
- Citizen（公民） + ship → Citizenship（公民權、國籍 → 身為國家公民的法定資格）。
- Owner（所有者） + ship → Ownership（所有權、物權）。
- Intern（實習生） + ship → Internship（實習期、實習職缺 → 當實習生的那段經歷）。

### ship專業技能與工藝
- Leader（領導者） + ship → Leadership（領導力、統御力 → 帶領團隊這艘大船前進的能力）。
- Scholar（學者） + ship → Scholarship（獎學金 / 學術成就 → 原指學者的學術造詣，後來引申為發給優秀學者的獎金）。
- Workman（工匠） + ship → Workmanship（手藝、工藝、做工 → 工匠展現出來的細緻技術）。
- Sportsman（運動員） + ship → Sportsmanship（運動員精神、運動風度）。

## ence/ance 名詞 具體的動作、過程、或結果
一種持續存在的【狀態】、【特質】或【性質】」，它不強調激烈的動作，而是強調「靜態的現象」。

- Differ（不同，動詞） → Difference（差異 → 兩個東西不一樣的結果）。
- Emerge（浮現） → Emergence（出現、興起 → 正在冒出來的過程，如：the emergence of AI）。
- Reside（居住） → Residence（住宅、住所 → 🌟 甚至直接固化成一個具體的建築物！）。

### ence 最愛黏在 字尾 -er、-exist、-end
#### er 結尾的動詞 → 偏愛 -ence：
- differ（相異） → difference（差異）
- prefer（偏好） → preference（偏好）
- interfer（干涉） → interference（干涉）

#### exist / -depend 系列的動詞 → 偏愛 -ence：
- exist（存在） → existence（存在狀態）
- depend（依賴） → dependence（依賴狀態）

## ence vs ency
- 字尾是 -ce 結尾： 畫面是「一件事、一個事實」（路上 80% 的字都是它）。
- 字尾是 -cy 結尾： 畫面是「一種狀態、一種能力、或一個機構」。

|基礎字|ence 結果或過程|ency 抽象狀態|
|:----------|:-----------|:-------------|
|Coincide(同時發生)|Coincidence巧合（一個具體發生的事件)|Coincidency一致性（事物互相符合的狀態）|
|Emerge(浮現)|Emergence興起、顯露（進行中的過程）|Emergency緊急事件（卡在危急中的狀態）|
|Persist(堅持)|Persistence堅持、固執（持續做的行為）|Persistency持久性（物理或化學上的無形性質）|

- Dependence (n.)： 指的是「依賴、依靠」這個行為或事實。
  - 例： Energy dependence（能源依賴 ➡️ 一國能源需要靠別國提供的事實）。
- Dependency (n.)： 指的是長期「處於依賴他人、無法自立的狀態」，甚至引申為「受保護的領地（屬地）」。
  - 例： Alcohol dependency（酒精依賴症 ➡️ 身體陷入無法自拔的狀態）。

- Emergence (n.)： 指的是一個東西「冒出來、出現」的那場動作或歷史事件。
  - 例： The emergence of new technologies（新科技的興起/出現這件事）。
- Emergency (n.)： 指的是突然冒出來、讓人措手不及的「緊急狀態」（如火災、急診）。

多數選 -ance（行為/事實）：
- Perform ➡️ Performance（表演 ➡️ 一場具體的行為）
- Import ➡️ Importance（重要性 ➡️ 一個客觀事實）
少數選 -ancy（特質/狀態/職位）：
- Vacant ➡️ Vacancy（空缺的狀態）
- Expectant ➡️ Expectancy（期待的狀態/預期值）

多數選 -ence（行為/事實）：
- Differ ➡️ Difference（不同之處 ➡️ 客觀事實）
- Exist ➡️ Existence（存在 ➡️ 客觀事實）
少數選 -ency（能力/狀態/機構）：
- Fluent ➡️ Fluency（流利的能力/特質）
- Agent ➡️ Agency（代理人運作的機構 ➡️ 代理商）


## 動詞 → ent(形) → ence(名)
- differ (動) → different (形) → difference (名)
- depend (動) → dependent (形：依賴的) → dependence (名：依賴)
- exist (動) → existent (形：存在的) → existence (名：存在)

## ent(形) → ence(名)
當它表示「處於某種動作的狀態中」，且它的名詞形是 -ence 或 -ency 時：
- silent（安靜的） → 名詞是 silence
- efficient（有效率的） → 名詞是 efficiency

## ous 形容詞
名詞 + ous = 形容詞

### ous 情感，充滿...的
- Danger（危險） + ous → Dangerous（危險的 → 裡面裝滿了危險）。
- Joy（喜悅） + ous → Joyous（喜悅的、歡樂的 → 充滿快樂的）。
- Poison（毒藥） + ous → Poisonous（有毒的 → 裡面全是毒）。
- Nerve（神經） + ous → Nervous（緊張的 → 渾身神經緊繃、充滿神經質的狀態）。

### ous 崇高、巨大、有名
形容偉大、令人驚嘆狀態的字，都喜歡用 -ous，來展現那種「分量感」
- Fame（名聲） + ous → Famous（著名的 → 滿身都是名氣）。
- Glory（榮耀） + ous → Glorious（光榮的、輝煌的）。
- Marvel（奇蹟） + ous → Marvelous（極好的、不可思議的 → 像奇蹟一樣令人驚嘆）。
- Courage（勇氣） + ous → Courageous（勇敢的 → 充滿勇氣的）。

其它形容詞
- Vary（改變/多樣） + ous → Various（各式各樣的 → 充滿變化的）。
- Continu-（連續） + ous → Continuous（連續不斷的 → 沒有中斷地一直充滿著）。

### osity
ous 形容詞 -> 變 -> os**ity** 名詞

- Generous（慷慨的） → Generosity（慷慨/大方，名詞）。
- Curious（好奇的） → Curiosity（好奇心，名詞）

例外:
- Anxious (Anx-ious, 焦慮的) → Anxiety (變體，焦慮名詞，重音跑到 e 身上)

##  重音 -ious / -eous / -uouos（形容詞字尾：滿滿的）

- Lux-u-ry（Lux-u-ry 奢侈，重音在最前） → Luxurious（奢侈的，重音跑到 u 身上）


## ive 形容詞
「動詞」尾巴是 t、d、s，-ive 100% 是它的第一首選。
動詞 (或動作字根) → 優先配 -ive 變形容詞

### 動詞 + ive = 形容詞
形容某個人或事物「很會做某個動作」或者「自帶那種功能」
- Act（行動） + ive → Active（活躍的、積極的 → 隨時都在動的狀態）。
- Create（創造） + ive → Creative（有創造力的 → 很會創造新東西的）。
- Talk（說話）的拉丁源頭 + ative（變體） → Talkative（健談的、愛說話的 → 很有說話傾向的）。

- Produce（生產） + ive → Productive（有生產力的、高效率的）。
- Compete（競爭） + ive → Competitive（有競爭力的、競爭激烈的）。
- Comprehensive（詳盡的、全面的 → 能夠把所有東西都包含進來的）。
- Effect（效果） + ive → Effective（有效的 → 能產生預期效果的）。
- Prevent（預防，動詞） → Preventive（預防性的）

### sive
動詞結尾發 d 或是 s 的音 → 為了好發音，會演變成 -sive

- Express 表達 → Expressive 表情豐富的

## ize/ise 動詞
名詞、形容詞還是字根，只要一接上 -ize，它就會 100% 轉化為「及物動詞」。

核心是「使成為...狀態、使...化、去執行某種特定動作」。

-ize 就是英文裡的 "Make..."（使其變成...）

### 名詞 + ize = 動詞「轉化成某種特定系統或行為」
把一個具體的東西或概念，變成一個可執行的程序：
- subsidy + ize = subsidize 資助
- Memory（記憶） + ize → Memorize（背誦）。
- Apology（道歉，名詞） + ize → Apologize（道歉）。
- Standard（標準） + ize → Standardize（使標準化 → 如：標準化測驗）。
- Global（全球的，源自 globe 地球） + ize → Globalize（使全球化）

### ize 把工作流程「概念化」
- Priority（優先權） → Prioritize（排定優先順序）。
- Optimize（優化、使完善 ）。
- Minimize（使減到最少、最小化） 
- Maximize（使增加到最大、最大化）

### 形容詞 + ize = 動詞「使成為...狀態」（使...化）
- Real（真實的） + ize → Realize（實現、意識到 → 使一件事變成真的）。
- Modern（現代的） + ize → Modernize（使現代化 → 使其具備現代的狀態）。
- Social（社交的/社會的） + ize → Socialize（進行社交、使社會化）。
- Final（最後的） + ize → Finalize（敲定、使終結 → 商務合約最後確認時必用）。

### ization 動詞變名詞
 -ize 動詞想要升級成我們學過的 -tion 名詞時，它們會合體變成 -ization（使...化的過程）

重音在tion的前一個音節

## -y 形容詞
- 短單字 + 簡單名詞 → 100% 是形容詞。
  - Rain (雨) → Rainy (下雨的)
  - Salt (鹽) → Salty (鹹的)
- 長單字 + 動作/拉丁/希臘字根底層 → 100% 是名詞。

### y形容詞 充滿...的
短的名詞 + y = 形容詞
- Rain（雨） + y → Rainy（下雨的、多雨的 → 滿天都是雨）。
- Sun（太陽） + y → Sunny（晴朗的、陽光充足的 → 🌟 重複字尾）。
- Luck（運氣） + y → Lucky（幸運的 → 滿身都是好運）。
- Taste（味道） + y → Tasty（美味的 → 充滿味道的 → 🌟 去 e 加 y）。

### y名詞 裝可愛的「小名與親暱稱呼」
- Dog（狗） → Doggy（狗狗、小狗）。
- Dad（爸爸） → Daddy（爹地、爸爸）。
- Sweet（甜的） → Sweetie（親愛的、甜心）。

### y名詞 行為、抽象狀態
- Honest（誠實的） + y → Honesty（誠實，名詞）。
- Dis-（不） + cover（覆蓋） + y → Discovery（發現，名詞 → 把覆蓋掀開的那個行為）。
- Deliver（遞送） + y → Delivery（遞送、外送，名詞 → 如：food delivery）。
- Subsidy 補助金、津貼 sub 在..下面 sid坐 y名詞

### 字根字尾r、s、t + y = 名詞 
拉丁文的動作字根尾巴是 -r-（轉動、流動）、-s- / -t-（動作完成的卡榫）時，後面極度喜歡加上 -y，將這個「動作的過程」固化為一個「抽象名詞」。

- Controversy（爭議） → contro-（反） + vers-（轉） + -y（名詞） → 意見轉向相反方向的狀態。
- Discovery（發現） → discover（發現，動詞） + -y（名詞） → 發現的行為。
- Inquiry（詢問/調查） → inquire（詢問，動詞） + -y（名詞） → 詢問的行為。
- Delivery（遞送） → deliver（遞送，動詞） + -y（名詞） → 遞送的行為/結果。
- Victory（勝利） → victor（征服者） + -y（名詞） → 獲勝的狀態。

### 字尾c + y =  名詞 代表「狀態、身分、制度」
融合成 -cy（代表「狀態、身分、制度」
- Privacy（隱私） → private（私人的） + -y → 處於私密、不公開的狀態。
- Democracy（民主） → demo（人民） + cracy（統治/制度） → 由人民統治的制度。

### 字尾t + y = 名詞 性質、程度、特徵
融合成 -ty 或 -ity（代表「性質、程度、特徵」
- Honesty（誠實） → honest（誠實的） + -y → 誠實的美德/性質。
- Ability（能力） → able（有能力的） + -ity → 具備能力的程度/狀態。

### y動詞：去執行某個特定的動作
少數動詞也以 -y 結尾，通常是名詞或字根直接轉過來的動作：
- Marry（結婚）
- Carry（攜帶）
- Copy（複製）
- destory (破壞)

- Abstra（往外拉） + ct → Abstract（抽象的，形容詞 / 摘要，名詞 → 🌟 從原本實體中被抽離出來的概念）。

### ct 固態
ct 其實是拉丁文動詞在進行「物理狀態變形」時，所留下來的「動作完成」卡榫！

flu（流動） + ct（固化）= 把水打包成「固態的粒子」= 固化成了一波、一波、有著具體起伏形狀的『波浪』

fluct + ate = 波動、起伏(動詞)

|基本單字|單字+ct|意思|
|:---------|:-----------|:------------------|
|stru- (建造/堆疊)|struct (結構/建築物)|從「正在堆東西」變成「蓋好的結構」|
|destru- (破壞)|destruct (毀滅/破壞的)|從「正在砸東西」變成「被砸爛的毀滅狀態」|
|condu- (引導)|conduct (行為/引導/傳導)|從「在前面帶路」變成「被引導出來的具體行為」|
|flu- (流動)|fluct (起伏波動)|從「平滑地流過」變成「一高一低的波浪」|

## th 名詞
 -th 發音，為了好唸，前面形容詞原本的長母音，通常會「縮水」變成短母音：

### 形容詞 + th = 名詞 該特質的度量衡或抽象狀態
- Wide（寬的，長音 [aɪ]） + -th
  - Width（寬度，母音縮水成短音 [ɪ]）。
- Deep（深的，長音 [i]） + -th
  - Depth（深度，母音縮水成短音 [ɛ]）。
- Long（長的，母音 [ɔ]） + -th
  - Length（長度，母音變音成 [ɛ]）。
- Strong（強壯的，母音 [ɔ]） + -th
  - Strength（力量/強度，母音變音成 [ɛ]）。
- Grow (成長)[ɡroʊ] → Growth[ɡroθ] (成長、增長)
- Heal[hil] (治癒) → Health[helθ] (健康)
- Warm[wɔrm]（溫暖的） + -th
  - Warmth[wɔmθ]（溫暖）。
- Broad[brɔd]（寬闊的） + -th
  - Breadth[bredθ]（幅員/寬廣）。



### 動詞 + th = 該動作產生的抽象結果
- Grow（成長，動詞） + -th  
  - Growth（成長/發育，名詞）。
- Heal（治癒，動詞） + -th 
  - Health（健康 → 物理畫面：身體被治癒後的完好狀態，母音同樣縮水成短音 [ɛ]）。
- Die（死亡，動詞） + -th
  - Death（死亡，名詞 → 底層拼寫發生了形變）。
- Steal（偷竊，動詞） + -th
  - Stealth（秘密行動/隱形 → 物理畫面：像小偷一樣鬼鬼祟祟的狀態）。
- Bear（誕生/承受，動詞） + -th
  - Birth（出生/誕生，名詞）。

th，專門用來把動詞/人轉成「抽象名詞、事件或結果」
