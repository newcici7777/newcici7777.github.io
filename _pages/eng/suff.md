## true 動作留下來的結果

動作留下來的「實體結果」
- mix混合 Mixture 
  - 混在一起之後產生的東西 → 混合物、混合狀態
- sign記號 Signature 
  - 簽完名後留在紙上的那個記號 → 簽名
- create創造 Creature 
  - 被上帝創造出來的成果 → 生物、造物、動物
- fract破裂 Fracture 
  - 骨頭或物體被折斷後的那個裂縫 → 骨折、裂縫

動作形成的「抽象狀態或結構」
- Failure fail (失敗)
  - 事情搞砸了的那個狀態 → 失敗、故障
- Structure struct (建造) 
  - 一步步建造起來的那個框架 → 結構、建築物
- Departure depart (出發/離開) 
  - 飛機或人離開的那個動作/過程 → 出發、離境
- Posture pos (放置/擺姿勢) 
  - 身體被放置、擺出來的形狀 → 姿勢、體態

結合特定的知識、行業或文化
- Culture cult (耕作/照顧)
  - 對心靈與土地的深耕與照料 → 文化、教養
- Agriculture agri (田地) + cult (耕作)
  - 在田地上耕作的技術與行業 → 農業
- Architecture
  - architect (建築師)
  - 建築師所做的這門專業與藝術 → 建築學、建築風格

## sure 內心感受、測量、核心狀態
抽象的狀態或測量
- Pleasure please (使高興)
  - 內心感到高興與滿足的狀態 → 愉快、榮幸、樂趣
- Measure mensus (測量)
  - 把東西的分量抓出來的過程 → 測量、計量 / 措施
- Pressure press (按壓)
  - 被狠狠往下壓、喘不過氣的狀態 → 壓力
- Closure close (關閉)
  - 一件事情被關上、畫下句點的狀態 → 結束、倒閉 /（心靈的）釋懷
- Exposure expose (暴露)
  - 被完全打開、暴露在外的狀態 → 暴露、曝光率

## it 走 (名詞)
it 放在單字尾巴時，通常代表一個「走、去、移動」的動作或結果

前面動詞+it 多半跟交通、移動、查看有關（如 往外走是 exit，跨過去是 transit，繞圈走是 circuit！）。

- Exit ex- (向外) + it (走)
  - 讓人可以「往外走」的地方 → 出口、離場
- Transit trans- (跨越) + it (走)
  - 從這區「走過去」另一區 → 過境、運輸、轉機
- Visit vis- (看) + it (走/去)
  - 為了看某人而「走過去」 → 拜訪、參觀
- Circuit circu- (圓圈) + it (走)
  - 圍繞著圓圈「走一圈」的路線 → 電路、巡迴、環形路線
- Audit aud- (聽) + it (走/去)
  - 古代官員「走過去旁聽」帳目匯報 → 審計、稽核、旁聽
- Inhabit in- (在裡面) + hab- (居住) + it
  - 走進去一個地方並在裡面定居 → 居住於、棲息

被動的狀態(ed→ it) 名詞+it(狀態/東西)   特別留意商務財務情境，它很常是跟錢、信用、審查有關的專業術語
- Credit：cred（相信）+ it 
  - **被信任**的狀態 → 信用、貸款、讚譽。
- Merit：mer（賺得/應得）+ it 
  - 應該得到的獎勵 → 優點、功績、價值。
- Deficit：de-（向下/缺乏）+ fac/fic（做）的變形 + it 
  - 做出來的錢往下掉、不夠的狀態 → 赤字、虧損
- deposit（存錢、留下、押金）de-（向下）+ pos 放置 + it
  - 錢放下，留下東西 → （存錢、留下、押金）

it小一號、精緻的東西
- Rabbit：兔子的古稱，自帶一種毛茸茸、小巧可愛的語感。
- Exhibit：ex-（向外）+ hib（拿/握住）+ it  
  - 拿出來放在外面的「小展品」，引申為展覽、陳列品。

## ite
-ite 就是 -it 的豪華長大版！ 它承襲了「被動、狀態」的基因。  
ite 是拉丁文的過去分詞，
為了讓前面的母音發長音，英文习惯在尾巴補上一個不發音的 e，於是就固定成了 -ite。

### 形容詞 已經完成了某個動作的狀態
這類字通常是由動詞演變而來的形容詞，代表「已經完成了某個動作的狀態」

- Opposite (形容詞/名詞)： op- (反方向) + pos (放置) + -ite 
  - 「被放在反方向的狀態」 → 相反的、對立的
- Definite：de- (向下/明確) + fin (界線) + ite 
  - 已經劃好界線、很明確的狀態 → 明確的、肯定的。
- Infinite：in- (否定) + fin (界線) + ite 
  - 沒有界線的狀態 → 無限的、無窮的。
- Polite：pol (擦亮/平滑) + ite 
  - 行為舉止像被擦拭得亮晶晶一樣 → 有禮貌的。

### 名詞 某個特定群體的人、追隨者
- Favorite：favor (喜愛) + ite → 被偏愛的那個人 → 最喜愛的人或物。
- Elite：選出來（elect）的優秀人群 → 菁英、優秀分子。
- Socialite：social (社交) + ite → 活躍於社交圈的人 → 名媛、社交名流。


## ent/ant
ent拉丁文中的ing，專門用來把動詞變成「正在做某事、具備某種狀態」的字尾。
所以會有形容詞跟名詞二種身份。

### 形容詞
形容某個人或事物的狀態
- Differ（不同） + ent → Different（不同的）。
- Depend（依賴） + ent → Dependent（依賴的、取決於...的）。
- Sil-（保持安靜） + ent → Silent（安靜的、沉默的）。
- Con-fide（信任） + ent → Confident（有信心的 → 內心充滿信任的）。

### 名詞
做這個動作的人
- Preside（主持、主席） + ent → President（總統、董事長 → 主持大局的人）。
- Reside（居住） + ent → Resident（居民、住戶 → 正在那裡居住的人）。
- Study（學習）的拉丁源頭 + ent → Student（學生 → 正在

產生的東西
- Nutri-（滋養） + ent → Nutrient（營養素、養分 → 帶來滋養的東西）。
- Ingredi-（走進去） + ent → Ingredient（原料、成分 → 走進去、加進去菜餚裡的東西）。
- Solv-（溶解） + ent → Solvent（溶劑 → 能把東西溶解掉的液體）

### 形容詞/名詞
可以為形容詞，也可為名詞，但意思不同

- Dependent
  - adj.依賴的、受扶養的
  - n.受扶養親屬、靠他人供養的人
- Patient
  - adj.有耐心的
  - n.病人（正在忍受痛苦的人）
- Executive (變體)
  - adj.執行的、行政的
  - n.高階主管、執行長（執行決策的人）
- Applicant (-ant)
  - adj.申請的
  - n.申請人、求職者


## age 名詞
動詞/名詞 + age = 集合名詞 或 抽象名詞  

### 總稱/集合名詞
- Bag（袋子） + age → Baggage（行李 → 所有的袋子、箱子打包在一起的總稱）。
- Pack（打包） + age → Package（包裹、整套方案 → 包在一起的一坨東西）。
- Garbage（垃圾） / Luggage（行李） 也是同樣的打包邏輯。

### 動詞動作發生的「過程、結果或場所」
代表做完某個動作後，所留下來的狀態、結果或做這件事的地點：
- Marry（結婚） + age → Marriage（婚姻 → 結婚之後的長久狀態）。
- Break（打破） + age → Breakage（破損、破損量 → 打破東西後的結果/數量）。
- Pass（通過） + age → Passage（通道、走廊、文章段落 → 讓人或文字通過的地方）。
- Store（儲存） + age → Storage（儲藏、儲存空間）。

### 做完某事要付的「費用」
- Post（郵寄） + age → Postage（郵資 → 郵寄信件要付的費用）。
- Port（港口） + age → Portage（搬運費、水運運費 → 貨物過港要付的錢）。

### 身分、地位、狀態
- Short（短缺的） + age → Shortage（短缺、不足的狀態）。
- Bond（連結/綁定） + age → Bondage（束縛、奴役狀態 → 被綁死死的狀態）。
- Host（主人） + age → Hostage（人質 → 古代住在人家家裡作為「擔保身分」的人，後來演變成被綁架的人質）。

## hood 名詞
### 代表生命的「某個特定時期、身分或狀態」
- Child（兒童） + hood → Childhood（童年 → 當兒童的那段黃金時期）。
- Mother（母親） + hood → Motherhood（母性、母親的身分 → 身為媽媽的狀態與職責）。
- Adult（成人） + hood → Adulthood（成年期）。
- False（虛假的） + hood → Falsehood（虛假、謊言 → 處於虛假的狀態中）。

### 住在同一個區域、或擁有共同特質的群體
- Neighbor（鄰居） + hood → Neighborhood（社區、鄰里 → 鄰居們共同生活、被罩在同一個生活圈的區域）。
- Brother（兄弟） + hood → Brotherhood（手足之情、兄弟會 → 擁有共同信念、像親兄弟一樣團結的群體）。
- Knight（騎士） + hood → Knighthood（騎士爵位、騎士階級 → 所有被授予騎士身分的人的總稱）。

## ship 名詞
這艘船上載著雙方的感情

### 人與人之間的「互動與關係」
- Friend（朋友） + ship → Friendship（友誼 → 朋友之間共同維繫的關係船）。
- Relation（關係） + ship → Relationship（戀愛/人際關係 → 專指兩個人之間深度的情感連結）。
- Partner（夥伴） + ship → Partnership（合夥關係、夥伴關係）。

### 法律、組織給予的「身分與資格」

- Citizen（公民） + ship → Citizenship（公民權、國籍 → 身為國家公民的法定資格）。
- Owner（所有者） + ship → Ownership（所有權、物權）。
- Intern（實習生） + ship → Internship（實習期、實習職缺 → 當實習生的那段經歷）。

### 專業技能與工藝
- Leader（領導者） + ship → Leadership（領導力、統御力 → 帶領團隊這艘大船前進的能力）。
- Scholar（學者） + ship → Scholarship（獎學金 / 學術成就 → 原指學者的學術造詣，後來引申為發給優秀學者的獎金）。
- Workman（工匠） + ship → Workmanship（手藝、工藝、做工 → 工匠展現出來的細緻技術）。
- Sportsman（運動員） + ship → Sportsmanship（運動員精神、運動風度）。

## -itude 名詞

### 測量
- Alt（高） + itude → Altitude（海拔、高度 → 處於多高的狀態）。
- Lat（寬、寬闊） + itude → Latitude（緯度 → 在地球上橫向寬度展開的度量）。
- Long（長） + itude → Longitude（經度 → 在地球上縱向長度延伸的度量）。
- Magn（大） + itude → Magnitude（巨大、震級/星等 → 地震有多大、或是星星有多亮的「巨大程度」）

### 心靈的抽象狀態
- Att-（源自 apt，適合、傾向） + itude → Attitude（態度、看法 → 內心傾向某個方向的狀態）。
- Grat（感激/高興） + itude → Gratitude（感激之情、感恩 → 內心充滿感謝的狀態）。
- Apt（適合/聰明） + itude → Aptitude（天資、才能/性向 → 身體或大腦適合做某件事的潛能狀態，如多益常考的 aptitude test 性向測驗）。
- Fort（強壯/勇敢） + itude → Fortitude（堅韌、剛毅 → 內心無比強壯的狀態）。

## ty/ity 狀態
把一個「形容詞」（...的），加上 ty 或 ity ，就會變成一個名詞（...的特質）。
- Safe（安全的） + ty → Safety（安全、安全性）。
- Cruel（殘忍的） + ty → Cruelty（殘忍、殘酷行為）。
- Pure（純淨的） + ity → Purity（純淨、純潔）。
- Simp-（簡單的） + icity（變體） → Simplicity（簡單、樸素）。

某種能力、營運指標或商品特質
- Able（有能力的） + ity → Ability（能力）。
- Productive（有生產力的） + ity → Productivity（生產力、生產率 → 多益核心大字！）。
- Creative（有創造力的） + ity → Creativity（創造力）。
- Flexible（有彈性的） + ity → Flexibility（彈性、靈活性 → 如：上班時間的彈性）。
- Quality（品質）
- Quantity（數量）
- Availability（可利用性/空位)

一整群人或一個整體（集合名詞），具備某種特質的人事物「打包成一個群體」
- Soc-（同伴/社會） + iety → Society（社會、協會 → 同伴們聚集在一起的整體）。
- Commun-（共同的） + ity → Community（社區、共同體 → 擁有共同生活特質的一群人）。
- Author（權威/原創者） + ity → Authority（權威、官方當局 → 具備說話分量的人或政府機構）。

### 何時加ty 或 ity
形容詞是 -e 結尾： 通常直接加 -ty。
- Safe → Safety 
- Pure → Purity（e 變成 i）。

形容詞是以 -ble 或 -al 結尾： 尾巴會軟化成 -bility 或 -ality。
- Possible → Possibility（可能性）
- Formal → Formality（正式手續）。

### ity 重音音節
重音在倒數第三個音節 
- Active → Ac`tivity（共 4 音節，倒數第三是 ti）
- Possible → Possi`bility（共 5 音節，倒數第三是 bi）

## ous 形容詞
名詞 + ous = 形容詞

情感，充滿...的
- Danger（危險） + ous → Dangerous（危險的 → 裡面裝滿了危險）。
- Joy（喜悅） + ous → Joyous（喜悅的、歡樂的 → 充滿快樂的）。
- Poison（毒藥） + ous → Poisonous（有毒的 → 裡面全是毒）。
- Nerve（神經） + ous → Nervous（緊張的 → 渾身神經緊繃、充滿神經質的狀態）。

崇高、巨大、有名，形容偉大、令人驚嘆狀態的字，都喜歡用 -ous 來展現那種「分量感」
- Fame（名聲） + ous → Famous（著名的 → 滿身都是名氣）。
- Glory（榮耀） + ous → Glorious（光榮的、輝煌的）。
- Marvel（奇蹟） + ous → Marvelous（極好的、不可思議的 → 像奇蹟一樣令人驚嘆）。
- Courage（勇氣） + ous → Courageous（勇敢的 → 充滿勇氣的）。

其它形容詞
- Vary（改變/多樣） + ous → Various（各式各樣的 → 充滿變化的）。
- Continu-（連續） + ous → Continuous（連續不斷的 → 沒有中斷地一直充滿著）。

### osity
ous 形容詞 -> 變 -> os**ity** 名詞

- Generous（慷慨的） → Generosity（慷慨/大方，名詞）。
- Curious（好奇的） → Curiosity（好奇心，名詞）

例外:
- Anxious (Anx-ious, 焦慮的) → Anxiety (變體，焦慮名詞，重音跑到 e 身上)

##  重音 -ious / -eous / -uouos（形容詞字尾：滿滿的）
只要 -ous 前面多了 i, e, u，重音就會被吸到前一格：
- Courage（勇氣，重音在最前） → Courageous（勇敢的，重音跑到 ra 身上）
- Injury（傷害，重音在最前） → Injurious（有害的，重音跑到 ju 身上）
- Lux-u-ry（Lux-u-ry 奢侈，重音在最前） → Luxurious（奢侈的，重音跑到 u 身上）


## ive 形容詞
動詞 + ive  
形容某個人或事物「很會做某個動作」或者「自帶那種功能」
- Act（行動） + ive → Active（活躍的、積極的 → 隨時都在動的狀態）。
- Create（創造） + ive → Creative（有創造力的 → 很會創造新東西的）。
- Talk（說話）的拉丁源頭 + ative（變體） → Talkative（健談的、愛說話的 → 很有說話傾向的）。
- Attract（吸引） + ive → Attractive（有吸引力的、迷人的 → 能夠把人吸引過來的）。

- Produce（生產） + ive → Productive（有生產力的、高效率的）。
- Compete（競爭） + ive → Competitive（有競爭力的、競爭激烈的）。
- Comprehensive（詳盡的、全面的 → 能夠把所有東西都包含進來的）。
- Effect（效果） + ive → Effective（有效的 → 能產生預期效果的）。

## ive 名詞
特定身分的人 或 抽象概念
- Execute（執行） + ive → Executive（高階主管、執行長 → 執行決策的人，如 CEO 裡的 E）。
- Represent（代表） + ive → Representative（業務代表、代理人 → 被派出來代表大家的人）。
- Object（反對/客觀） + ive → Objective（目標、目的 → 往前走要達到的地方）。
- Incent（激勵） + ive → Incentive（誘因、獎勵金 → 能夠激勵你行動的東西）。
 
變成副詞： 100% 直接加 -ly 
- Actively（積極地）
- Creatively（有創意地）。

變成名詞： 很多時候會跟我們學過的 -ity 結合，合體成 -ivity！
- Active → Activity（活動）

## ate
