## true 藝術、建築、手工藝相關的詞彙
### 動作留下來的「實體結果」
- mix混合 Mixture 
  - 混在一起之後產生的東西 → 混合物、混合狀態
- sign記號 Signature 
  - 簽完名後留在紙上的那個記號 → 簽名
- create創造 Creature 
  - 被上帝創造出來的成果 → 生物、造物、動物
- fract破裂 Fracture 
  - 骨頭或物體被折斷後的那個裂縫 → 骨折、裂縫

### 動作形成的「抽象狀態或結構」
- Failure fail (失敗)
  - 事情搞砸了的那個狀態 → 失敗、故障
- Structure struct (建造) 
  - 一步步建造起來的那個框架 → 結構、建築物
- Departure depart (出發/離開) 
  - 飛機或人離開的那個動作/過程 → 出發、離境
- Posture pos (放置/擺姿勢) 
  - 身體被放置、擺出來的形狀 → 姿勢、體態

### 結合特定的知識、行業或文化
- Culture cult (耕作/照顧)
  - 對心靈與土地的深耕與照料 → 文化、教養
- Agriculture agri (田地) + cult (耕作)
  - 在田地上耕作的技術與行業 → 農業
- Architecture
  - architect (建築師)
  - 建築師所做的這門專業與藝術 → 建築學、建築風格

## sure 內心感受、測量、核心狀態
動詞的字尾 d 或 s，為了發音順暢，改成sure

### 抽象的狀態或測量
- Pleasure please (使高興)
  - 內心感到高興與滿足的狀態 → 愉快、榮幸、樂趣
- Measure mensus (測量)
  - 把東西的分量抓出來的過程 → 測量、計量 / 措施
- Pressure press (按壓)
  - 被狠狠往下壓、喘不過氣的狀態 → 壓力
- Closure close (關閉)
  - 一件事情被關上、畫下句點的狀態 → 結束、倒閉 /（心靈的）釋懷
- Exposure expose (暴露)
  - 被完全打開、暴露在外的狀態 → 暴露、曝光率

## it 走 (名詞)
it 放在單字尾巴時，通常代表一個「走、去、移動」的動作或結果
### 交通、移動、查看
前面動詞+it 多半跟交通、移動、查看有關（如 往外走是 exit，跨過去是 transit，繞圈走是 circuit！）。

- Exit ex- (向外) + it (走)
  - 讓人可以「往外走」的地方 → 出口、離場
- Transit trans- (跨越) + it (走)
  - 從這區「走過去」另一區 → 過境、運輸、轉機
- Visit vis- (看) + it (走/去)
  - 為了看某人而「走過去」 → 拜訪、參觀
- Circuit circu- (圓圈) + it (走)
  - cu念c，u不發音
  - 圍繞著圓圈「走一圈」的路線 → 電路、巡迴、環形路線
- Audit aud- (聽) + it (走/去)
  - 古代官員「走過去旁聽」帳目匯報 → 審計、稽核、旁聽
- Inhabit in- (在裡面) + hab- (居住) + it
  - 走進去一個地方並在裡面定居 → 居住於、棲息

### 被動的狀態(ed→ it) 
名詞+it(狀態/東西)   特別留意商務財務情境，它很常是跟錢、信用、審查有關的專業術語
- Credit：cred（相信）+ it 
  - **被信任**的狀態 → 信用、貸款、讚譽。
- Merit：mer（賺得/應得）+ it 
  - 應該得到的獎勵 → 優點、功績、價值。
- Deficit：de-（向下/缺乏）+ fac/fic（做）的變形 + it 
  - 做出來的錢往下掉、不夠的狀態 → 赤字、虧損
- deposit（存錢、留下、押金）de-（向下）+ pos 放置 + it
  - 錢放下，留下東西 → （存錢、留下、押金）

### it小一號、精緻的東西
- Rabbit：兔子的古稱，自帶一種毛茸茸、小巧可愛的語感。
- Exhibit：ex-（向外）+ hib（拿/握住）+ it  
  - 拿出來放在外面的「小展品」，引申為展覽、陳列品。

## ite 
ite 是拉丁文的過去分詞，
為了讓前面的母音發長音，英文习惯在尾巴補上一個不發音的 e，於是就固定成了 -ite。

### 抽象的形容詞
抽象字根 + ite = 形容詞

- Opposite (形容詞/名詞)： op- (反方向) + pos (放置) + -ite 
  - 「被放在反方向的狀態」 → 相反的、對立的
- Definite：de- (向下/明確) + fin (界線) + ite 
  - 已經劃好界線、很明確的狀態 → 明確的、肯定的。
- Infinite：in- (否定) + fin (界線) + ite 
  - 沒有界線的狀態 → 無限的、無窮的。
- Polite：pol (擦亮/平滑) + ite 
  - 行為舉止像被擦拭得亮晶晶一樣 → 有禮貌的。

### 名詞 人或物
- Favorite：favor (喜愛) + ite → 被偏愛的那個人 → 最喜愛的人或物。
- Elite：選出來（elect）的優秀人群 → 菁英、優秀分子。
- Socialite：social (社交) + ite → 活躍於社交圈的人 → 名媛、社交名流。

## ent/ant
ent拉丁文中的ing，專門用來把動詞變成「正在做某事、具備某種狀態」的字尾。
所以會有形容詞跟名詞二種身份。

### 形容詞
形容某個人或事物的狀態
- Differ（不同） + ent → Different（不同的）。
- Depend（依賴） + ent → Dependent（依賴的、取決於...的）。
- Sil-（保持安靜） + ent → Silent（安靜的、沉默的）。
- Con-fide（信任） + ent → Confident（有信心的 → 內心充滿信任的）。

### 名詞 人
做這個動作的人
- Preside（主持、主席） + ent 
  - President（總統、董事長 → 主持大局的人）。
- Reside（居住） + ent 
  - Resident（居民、住戶 → 正在那裡居住的人）。
- Study（學習）的拉丁源頭 + ent 
  - Student（學生 → 正在

### 名詞 產生的東西
- Nutri-（滋養） + ent 
  - Nutrient（營養素、養分 → 帶來滋養的東西）。
- Ingredi-（走進去） + ent 
  - Ingredient（原料、成分 → 走進去、加進去菜餚裡的東西）。
- Solv-（溶解） + ent 
  - Solvent（溶劑 → 能把東西溶解掉的液體）

### 形容詞/名詞
可以為形容詞，也可為名詞，但意思不同
- Dependent
  - adj.依賴的、受扶養的
  - n.受扶養親屬、靠他人供養的人
- Patient
  - adj.有耐心的
  - n.病人（正在忍受痛苦的人）
- Executive (變體)
  - adj.執行的、行政的
  - n.高階主管、執行長（執行決策的人）
- Applicant (-ant)
  - adj.申請的
  - n.申請人、求職者

## ency/ancy 名詞 抽象的狀態/行為/機構
重音在ency/ancy 前一個音節。

- 形容詞尾：-ent / -ant（例如：fluent 流利的、agent 代理的）
- 名詞字尾：-ency / -ancy（例如：fluency 流暢度、agency 代理處）

正在進行某個動作、或處於某種特定狀態下的『特質、行為、或機構』
- Fluency(流暢度)
  - Flu-（流動，動詞）
  - 正在流暢地流動的這種「狀態與特質」。
- Agency (代理處/局)
  - Ag-（去做、執行，動詞）
  - 替別人去執行、去運作的那個「機構或媒介」。
- Emergency(緊急事件)
  - Emerge（浮現、突然出現，動詞）
  - 突然浮現、冒出來需要立刻處理的「緊急狀態」。
- Presidency(總統職位/任期)
  - Preside（主持、坐在前面掌控）
  - 坐在最前面主持大局的這個「職位與任期狀態」。

## ence/ance 名詞 具體的動作、過程、或結果
- Differ（不同，動詞） → Difference（差異 → 兩個東西不一樣的結果）。
- Emerge（浮現） → Emergence（出現、興起 → 正在冒出來的過程，如：the emergence of AI）。
- Reside（居住） → Residence（住宅、住所 → 🌟 甚至直接固化成一個具體的建築物！）。

|基礎字|ence 結果或過程|ency 抽象狀態|
|:----------|:-----------|:-------------|
|Coincide(同時發生)|Coincidence巧合（一個具體發生的事件）
|Coincidency一致性（事物互相符合的狀態）|

## age 名詞
動詞 + age = 動作的過程、結果
名詞 + age = 費用/集合名詞/狀態  

### 總稱/集合名詞
- Bag（袋子） + age → Baggage（行李 → 所有的袋子、箱子打包在一起的總稱）。
- Pack（打包） + age → Package（包裹、整套方案 → 包在一起的一坨東西）。
- Garbage（垃圾） / Luggage（行李） 也是同樣的打包邏輯。

「打包」起來的總數
- Percent（百分比，名詞） + -age → Percentage（百分比/比例）。
- Mile（英里，名詞） + -age → Mileage（里程數 → 一英里一英里「累積打包」起來的總數）。

### 動詞動作發生的「過程、結果或場所」
代表做完某個動作後，所留下來的狀態、結果或做這件事的地點：
- Marry（結婚） + age → Marriage（婚姻 → 結婚之後的長久狀態）。
- Break（打破） + age → Breakage（破損、破損量 → 打破東西後的結果/數量）。
- Pass（通過） + age → Passage（通道、走廊、文章段落 → 讓人或文字通過的地方）。
- Store（儲存） + age → Storage（儲藏、儲存空間）。
- Wreck（毀壞，動詞） + -age → Wreckage（殘骸 → 毀壞後「打包」留下來的廢墟垃圾）。
- Drain（排水，動詞） + -age → Drainage（排水系統/排水量 → 排水這個動作的整體運作）。
- Leak（漏，動詞） + -age → Leakage（洩漏、漏出量 → 漏出來的那個狀態或東西）。
- Pack（打包，動詞） + -age → Package（包裹 → 打包好的那個實體物品）。
- Damage（損害)

### 做完某事要付的「費用」
- Post（郵寄） + age → Postage（郵資 → 郵寄信件要付的費用）。
- Port（港口） + age → Portage（搬運費、水運運費 → 貨物過港要付的錢）。
- Store（儲存，動詞） + -age → Storage（儲藏/倉儲費 → 儲存空間或其費用）。

### 身分、地位、狀態
- Short（短缺的） + age → Shortage（短缺、不足的狀態）。
- Bond（連結/綁定） + age → Bondage（束縛、奴役狀態 → 被綁死死的狀態）。
- Host（主人） + age → Hostage（人質 → 古代住在人家家裡作為「擔保身分」的人，後來演變成被綁架的人質）。

## hood 名詞
### 代表生命的「某個特定時期、身分或狀態」
- Child（兒童） + hood → Childhood（童年 → 當兒童的那段黃金時期）。
- Mother（母親） + hood → Motherhood（母性、母親的身分 → 身為媽媽的狀態與職責）。
- Adult（成人） + hood → Adulthood（成年期）。
- False（虛假的） + hood → Falsehood（虛假、謊言 → 處於虛假的狀態中）。

### 住在同一個區域、或擁有共同特質的群體
- Neighbor（鄰居） + hood → Neighborhood（社區、鄰里 → 鄰居們共同生活、被罩在同一個生活圈的區域）。
- Brother（兄弟） + hood → Brotherhood（手足之情、兄弟會 → 擁有共同信念、像親兄弟一樣團結的群體）。
- Knight（騎士） + hood → Knighthood（騎士爵位、騎士階級 → 所有被授予騎士身分的人的總稱）。

## ship 名詞
這艘船上載著雙方的感情

### 人與人之間的「互動與關係」
- Friend（朋友） + ship → Friendship（友誼 → 朋友之間共同維繫的關係船）。
- Relation（關係） + ship → Relationship（戀愛/人際關係 → 專指兩個人之間深度的情感連結）。
- Partner（夥伴） + ship → Partnership（合夥關係、夥伴關係）。

### 法律、組織給予的「身分與資格」
- Member（會員） + ship → Membership（會員資格 → 讓你能待在會員這艘船上的權利）。
- Citizen（公民） + ship → Citizenship（公民權、國籍 → 身為國家公民的法定資格）。
- Owner（所有者） + ship → Ownership（所有權、物權）。
- Intern（實習生） + ship → Internship（實習期、實習職缺 → 當實習生的那段經歷）。

### 專業技能與工藝
- Leader（領導者） + ship → Leadership（領導力、統御力 → 帶領團隊這艘大船前進的能力）。
- Scholar（學者） + ship → Scholarship（獎學金 / 學術成就 → 原指學者的學術造詣，後來引申為發給優秀學者的獎金）。
- Workman（工匠） + ship → Workmanship（手藝、工藝、做工 → 工匠展現出來的細緻技術）。
- Sportsman（運動員） + ship → Sportsmanship（運動員精神、運動風度）。

## logy, graphy, tomy, ity 重音倒數第三個
倒數第三音節規則（Antepenultimate Stress) 當一個單字是以 -ity、-graphy、-logy（學問）或 -tomy 結尾時，英文的發音習慣會強迫把重音放在整個單字的「倒數第三個音節」。

- Photograph（照片)
  - Pho`tography（攝影學，重音在 to）

## -itude 名詞
### 測量
- Alt（高） + itude → Altitude（海拔、高度 → 處於多高的狀態）。
- Lat（寬、寬闊） + itude → Latitude（緯度 → 在地球上橫向寬度展開的度量）。
- Long（長） + itude → Longitude（經度 → 在地球上縱向長度延伸的度量）。
- Magn（大） + itude → Magnitude（巨大、震級/星等 → 地震有多大、或是星星有多亮的「巨大程度」）

### 心靈的抽象狀態
- Att-（源自 apt，適合、傾向） + itude → Attitude（態度、看法 → 內心傾向某個方向的狀態）。
- Grat（感激/高興） + itude → Gratitude（感激之情、感恩 → 內心充滿感謝的狀態）。
- Apt（適合/聰明） + itude → Aptitude（天資、才能/性向 → 身體或大腦適合做某件事的潛能狀態，如多益常考的 aptitude test 性向測驗）。
- Fort（強壯/勇敢） + itude → Fortitude（堅韌、剛毅 → 內心無比強壯的狀態）。

## ty/ity 名詞

### 何時加ty 或 ity
形容詞是 -e 結尾： 通常直接加 -ty。
- Safe → Safety 
- Pure → Purity（e 變成 i）。

- 字尾ble，去e + ity
- 字尾al + ity
- 字尾是l + ity
- 字尾ive + ity

- Possible → Possibility（可能性）
- Formal → Formality（正式手續）。

### 形容詞 + ty = 名詞 ...的特質  
形容詞 + ty = 名詞 ...的特質  
把一個「形容詞」（...的），加上 ty 或 ity ，就會變成一個名詞（...的特質）。
- Safe（安全的） + ty → Safety（安全、安全性）。
- Cruel（殘忍的） + ty → Cruelty（殘忍、殘酷行為）。
- Pure（純淨的） + ity → Purity（純淨、純潔）。
- Simp-（簡單的） + icity（變體） → Simplicity（簡單、樸素）。

### 某種能力、營運指標或商品特質
名詞/形容詞 + ty/ity = 名詞  

- Able（有能力的） + ity 
  - Ability（能力）。
- Productive（有生產力的） + ity 
  - Productivity（生產力、生產率 ）。
- Creative（有創造力的） + ity 
  - Creativity（創造力）。
- Flexible（有彈性的） + ity
  - Flexibility（彈性、靈活性 → 如：上班時間的彈性）。
- Quality（品質）qual + ity
- Quantity（數量）
- Availability（可利用性/空位)

### 一整群人或一個整體（集合名詞）
具備某種特質的人事物「打包成一個群體」
- Soc-（同伴/社會） + iety 
  - Society（社會、協會 → 同伴們聚集在一起的整體）。
- Commun-（共同的） + ity 
  - Community（社區、共同體 → 擁有共同生活特質的一群人）。
- Author（權威/原創者） + ity 
  - Authority（權威、官方當局 → 具備說話分量的人或政府機構）。

### ity 重音音節
重音在倒數第三個音節 
- Active → Ac`tivity（共 4 音節，倒數第三是 ti）
- Possible → Possi`bility（共 5 音節，倒數第三是 bi）

## ous 形容詞
名詞 + ous = 形容詞

### 情感，充滿...的
- Danger（危險） + ous → Dangerous（危險的 → 裡面裝滿了危險）。
- Joy（喜悅） + ous → Joyous（喜悅的、歡樂的 → 充滿快樂的）。
- Poison（毒藥） + ous → Poisonous（有毒的 → 裡面全是毒）。

## -y
- 短單字 + 簡單名詞 → 100% 是形容詞。
  - Rain (雨) → Rainy (下雨的)
  - Salt (鹽) → Salty (鹹的)
- 長單字 + 動作/拉丁/希臘字根底層 → 100% 是名詞。

### 形容詞 充滿...的
短的名詞 + y = 形容詞
- Rain（雨） + y → Rainy（下雨的、多雨的 → 滿天都是雨）。
- Sun（太陽） + y → Sunny（晴朗的、陽光充足的 → 🌟 重複字尾）。
- Luck（運氣） + y → Lucky（幸運的 → 滿身都是好運）。
- Taste（味道） + y → Tasty（美味的 → 充滿味道的 → 🌟 去 e 加 y）。

### 名詞 裝可愛的「小名與親暱稱呼」
- Dog（狗） → Doggy（狗狗、小狗）。
- Dad（爸爸） → Daddy（爹地、爸爸）。
- Sweet（甜的） → Sweetie（親愛的、甜心）。

### 名詞 行為、抽象狀態
- Honest（誠實的） + y → Honesty（誠實，名詞）。
- Dis-（不） + cover（覆蓋） + y → Discovery（發現，名詞 → 把覆蓋掀開的那個行為）。
- Deliver（遞送） + y → Delivery（遞送、外送，名詞 → 如：food delivery）。
- Subsidy 補助金、津貼 sub 在..下面 sid坐 y名詞

### 字尾r、s、t + y 名詞 
拉丁文的動作字根尾巴是 -r-（轉動、流動）、-s- / -t-（動作完成的卡榫）時，後面極度喜歡加上 -y，將這個「動作的過程」固化為一個「抽象名詞」。

- Controversy（爭議） → contro-（反） + vers-（轉） + -y（名詞） → 意見轉向相反方向的狀態。
- Discovery（發現） → discover（發現，動詞） + -y（名詞） → 發現的行為。
- Inquiry（詢問/調查） → inquire（詢問，動詞） + -y（名詞） → 詢問的行為。
- Delivery（遞送） → deliver（遞送，動詞） + -y（名詞） → 遞送的行為/結果。
- Victory（勝利） → victor（征服者） + -y（名詞） → 獲勝的狀態。

### 字尾c + y 名詞 代表「狀態、身分、制度」
融合成 -cy（代表「狀態、身分、制度」
- Privacy（隱私） → private（私人的） + -y → 處於私密、不公開的狀態。
- Democracy（民主） → demo（人民） + cracy（統治/制度） → 由人民統治的制度。

### 字尾t + y 性質、程度、特徵
融合成 -ty 或 -ity（代表「性質、程度、特徵」
- Honesty（誠實） → honest（誠實的） + -y → 誠實的美德/性質。
- Ability（能力） → able（有能力的） + -ity → 具備能力的程度/狀態。

## le el
- le（動態大師）： 前面最常搭配**「雙子音」或「短動作」，代表「連續、重複的小動作（動詞）」（如 wiggle, struggle）或「小工具（名詞）」**（如 handle）。
- el（縮小大師）： 前面搭配**「大實體」，代表「縮小版、容器、精緻的實體（名詞）」**（如 satchel, chapel, model）。

###「重複動作」+ le 變成【動詞】
- Bub（泡泡音） + -le → Bubble（起泡、冒泡 → 泡泡一直咕嚕咕嚕冒出來）。
- Strugg（掙扎） + -le → Struggle（掙扎 → 手腳一直重複揮動）。
- Tack（釘住/抓住） + -le → Tackle（處理/擒抱 → 重複糾纏、抓住對手）。
- Wigg（擺動） + -le → Wiggle（扭動 → 屁股一直左搖右擺）。

### 搭配「動作字根」+ le 變成【小工具名詞】
- Hand（手） + -le → Handle（把手 → 手一直去抓的那個小東西）。

### 「大概念名詞」+ el 變成【縮小版名詞】
- Chap（教堂/capella） + -el → Chapel（小教堂 → 比 大教堂 Cathedral 還要小的禮拜堂）。
- Tun（大木桶） + -el → Tunnel（隧道 → 像木桶管道一樣，長長小小的通道）。

###「結構或物理概念」+ el 變成【基礎物理名詞】
- Mod（測量/標準） + -el → Model（模型/模範 → 縮小版的標準比例物）。
- Vess（血管/容器） + -el → Vessel（船隻/容器/血管 → 用來裝液體的精緻載體）。
- Kern（穀物/核心） + -el → Kernel（果仁/核心 → 最微小、最硬的那顆心）。
