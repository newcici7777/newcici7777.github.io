## which 當主詞
當主詞（後面直接接動詞）：
- Which hero will save the day?（哪位英雄會拯救危機？）
  - Which hero 是主詞（執行動作的人）。
* Which movie is playing tonight?（哪部電影今晚上映？ → 電影是主詞）

## which 當受詞
當受詞（助動詞後面接「人 + 一般動詞」）：
- Which hero do you like best?（你最喜歡哪位英雄？）
  - Which hero 是受詞（接收「喜歡」這個動作的對象）
- Which movie did you watch?（你看了哪部電影？ → 電影是受詞）

## which 當 形容詞
which作為形容詞，修飾後面的名詞。  
有作為分類的意思，那一個/什麼樣的/ 那一個種類  

只要把你想問的「種類（名詞）」放在 Which 後面，就可以無限延伸

### which + [種類] 
- Which cat is the fattest? (那一隻貓)
- Which month is the hottest (那一個月份)
- Which room is bigger, the living room or the kitchen?(那一間房間)
- Which trip is the most exciting?(那一個短程旅行)
- Which street are you looking for?(你在找哪一条街？)
- Which house will you choose? 你会选择哪个房子？ 

1. Which + 職業/人物
* Which hero（哪位英雄）
* Which teacher（哪位老師）

2. Which + 東西/物品
* Which car（哪輛車）
* Which book（哪本書）

3. Which + 時間/抽象概念
* Which day（哪一天）
* Which way（哪一條路 / 哪個方法）

## Which 介系詞結尾
```
 Which + 名詞 ... [介系詞]
```
- Which meeting room are you in
  - 原本是：You are in [which meeting room].（你在哪一間會議室裡面。）
  - 把疑問詞 Which meeting room 移到句首變成問句時，介系詞 in 就會自然而然地留在句尾。
- What hotel are you staying at?（你住哪一家飯店？——at 也是留在句尾）


## where 與 which 比較
Which meeting room（哪一間會議室）只是一個「名詞」，它本身沒有「in在裡面」的意思。

where 的組成其實就是 at/in/on + which place（在某個地方）。

- ❌ Where are you in?
- 在什麼地方的裡面，你在裡面？這在英文裡是錯的。

因此，當你想問「人在哪裡」時，直接用 where 當作介系詞的受詞即可：
- Where are you?（你在哪裡？——不加 in）
- Where are you staying?（你住在哪裡？——不需要在後面加 at）
- Where are you going?（你要去哪裡？——不加 to，因為 where 已經包含方向了）

- ❌ Which meeting room are you?（哪一間會議室你是？）
  - 人怎麼會變成一間會議室？
  - 必須明確表達：你是在哪一間會議室「裡面」。

- 原本是：You are in [which meeting room].
  - 把 which meeting room 提到句首變成疑問句時，後面的介系詞 in 就被留下來了： 
  - Which meeting room are you in?（你在哪一間會議室裡面？）

## 用 Which + 名詞（需要介系詞來交代位置或關係）
- Which meeting room are you in?（你在哪一間會議室？）
- Which team are you in?（你在哪一個團隊？）
- Which hotel are you staying at?（你住在哪一家飯店？）

### 空間與位置情境（Location）
用來詢問人或物體確切在哪個房間、座位或實體空間內。
- Which office are you in? （你在哪一間辦公室？）
- Which seat are you sitting in? （你坐在哪一個座位上？）
- Which building does he work in? （他在哪一棟大樓裡工作？）

### 組織、團隊與群體情境（Group / Organization）
用來詢問人被分配到哪一個部門、小組或班級。
- Which team are you on? （你在哪一個團隊裡？——註：團體通常用介系詞 on）
- Which department is she in? （她在哪一個部門？）
- Which class are you in this semester? （你這學期在哪一個班級？）

### 生活與旅宿情境（Lifestyle / Travel）
用來詢問住在哪家飯店、搭乘哪班車、或看哪本書。
- Which hotel are you staying at? （你住在哪一家飯店？）
- Which platform is the train waiting at? （火車停在哪一個月台？）
- Which page are we on? （我們翻到第幾頁了？）
- Which drawer did you put the keys in? （你把鑰匙放在哪一個抽屜裡？）

## 介系詞結尾

這是一個非常經典的英文日常口語句型！當你預約剪頭髮、看醫生或訂位時，櫃檯人員一定會對你說這句話。

我們來拆解為什麼句尾會有 **`for`**，以及它的原句與還原過程：

---

### 1. 為什麼句尾有 `for`？（介系詞懸空）

在英文的問句中，如果動詞或片語需要搭配介系詞（例如 *make an appointment **for** sth.*，為……預約時間），當我們把「預約的時間（疑問詞 what time）」提到句首變成問句時，**那個介系詞 `for` 就會被留在句子的最後面**。

這在口語和日常書信中非常自然，是標準的英文文法結構。

---

### 2. 它的原句（直述句）是什麼？

要理解這個問句，我們可以把問句「還原」成一般的直述句：

* **直述句結構：**
* You would like to make an appointment **for [某個時間]**.
* （你想要為**某個時間**預約。）


* **變成問句的過程：**
1. 把原本在後面的時間改成疑問詞 **`What time`**（幾點）。
2. 把疑問詞移到句首。
3. 句尾就只剩下原本跟著時間的那個 **`for`**。


* **演變結果：**
* ➡️ **`What time would you like to make an appointment for?`**
* （直譯：你想要為幾點預約一個約診？ ➡️ **你想預約幾點？**）



---

### 💡 類似的常見句型

這種「介系詞被留到句尾」的問句在生活中非常多，例如：

* *What are you looking **for**?*（你在找什麼？ ➡️ *You are looking for what.*）
* *Who did you talk **to**?*（你跟誰講話？ ➡️ *You talked to who.*）

所以，句尾的 `for` 就是跟著 `appointment` 一起用來指「預約（某個時間）」的喔！
