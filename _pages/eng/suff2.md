## 動詞 → 形容詞
動詞尾巴有 t 或 d → 優先配 -ive
- Act（動詞） → 尾巴是 t → 配 -ive → Active（活躍的）
- Create（動詞） → 尾巴是 t → 配 -ive → Creative（有創意的）
- Defend（防守） → 尾巴是 d → 配 -ive → Defensive（防衛性的，d 融化成 s）

動詞是 -ate 結尾 → 優先配 -ive 或 -ory
- Appreciate（感激） → Appreciative（感激的）
- Decorate（裝飾） → Decorative（裝飾性的）
- Prepare（準備，來自拉丁字根 parat-） → Preparatory（準備的/預備的）

## 動詞 → 名詞
動詞尾巴有 t 或 ate → 配 -tion  
代表「抽象的動作、過程或概念」
- Act → Action（行動）
- Create → Creation（創造）
- Translate → Translation（翻譯）

動詞是「單音節」或「原生動詞」 → 優先配 -ment
- Pay（付錢） → Payment（付款）
- Agree（同意） → Agreement（協議）
- Develop（發展） → Development（發展）

動詞尾巴是 ss → 配 -ure 或 -sure [ʃər]
- Press（壓） → 配 -ure → Pressure（壓力 → s 融合成 sh 的音）

動詞尾巴是 se（發有磁性的 [z] 音）時，去掉尾巴不發音的 e，加上 -ure 
[ʒər]
- Close（關閉） → 配 -ure → Closure（結束/倒閉）
- Expose（暴露，動詞） → 去掉 e 加上 -ure → Exposure（暴露/曝光，名詞 ）
- Please（使取悅，動詞） → 去掉 e 加上 -ure → Pleasure（榮幸/快樂，名詞）

尾巴是 t → 配 -ure 融合成 ture [tʃər]  
true 具體發生的事件、結果
- Depart（出發，動詞） + -ure → Departure（出發/離境，名詞）
- Sign（簽名） → 加上拉丁動態字根變體 signat + -ure → Signature（簽名，名詞 ）

## 名詞 → 形容詞
名詞 + ous 
- Danger（危險，名詞） → 配 -ous → Dangerous（危險的）
- Fame（名譽，名詞） → 去 e 配 -ous → Famous（著名的）
- Mystery（神秘，名詞） → 變 y 為 i 配 -ous → Mysterious（神秘的）

## 形容詞 → 名詞
形容詞 -able / -ible → 名詞 -ability / -ibility
- Capable（有能力的） → Capability（能力）
- Flexible（有彈性的） → Flexibility（彈性）
- Reliable（可靠的） → Reliability（可靠性）

形容詞 -ive → 名詞 -ivity
- Creative（有創意的） → Creativity（創意/創造力）
- Active（活躍的） → Activity（活動/活力）
- Productive（有生產力的） → Productivity（生產力）

形容詞 -al → 名詞 -ality
- Personal（個人的） → Personality（個性/人格）
- Formal（正式的） → Formality（禮節/正式程序）
- Real（真實的） → Reality（現實 → 🌟 重音搬家到 al 身上）

以下都是形容詞

## ive 形容詞
前方通常是「動詞」或「動作字根」。
如果動詞尾巴是 t、d、s ，-ive 100% 是它的第一首選。
- Act（行動） → Active（主動的、活躍的 → 一直在動）
- Create（創造） → Creative（有創意的 → 一直在創造）
- Talk（說話） → Talkative（多話的 → 傾向一直講話，中間加了 at 緩衝）

## ent 形容詞
ent/ant 接在「動詞」後面
- Differ（不同） → Different（不同的 → 呈現出不一樣的狀態）
- Excel（優秀） → Excellent（優秀的）
- Rely（依賴） → Reliant（依賴的 → 變 y 為 i，呈現依賴的狀態）
- Please（使取悅） → Pleasant（令人愉快的）


## ary ory 與...有關的
ary 喜歡黏在「名詞」後面。
- Document（文件，名詞） → Documentary（紀錄片的/文件的 → 與文件紀錄有關的）
- Custom（習慣，名詞） → Customary（慣例的）

ory 則偏愛黏在動詞後面。
- Introduce（介紹，動詞） → Introductory（介紹的、入門的）
- Satisfy（滿足，動詞） → Satisfactory（令人滿意的）

## al 屬於...領域的
喜歡跟在「抽象名詞」的後面
- Nation（國家） → National（國家的 → 與國家領域有關的）
- Nature（自然） → Natural（自然的 → 丟掉 e 配 -al）
- Music（音樂） → Musical（音樂的）

## ous 充滿了...
幾乎只黏在「具體的名詞」或「情緒名詞」屁股後面
- Danger（危險，名詞） → Dangerous（危險的 → 裡面充滿了危險）
- Poison（毒藥，名詞） → Poisonous（有毒的 → 充滿了毒素）
- Fame（名聲，名詞） → Famous（著名的 → 充滿了名氣）

## y 形容詞
專挑最簡單、最古老、單音節的「古英文生活名詞」（如天氣、食物、感官）
- Rain（雨） → Rainy（下雨的）
- Dirt（泥土） → Dirty（髒的）
- Salt（鹽） → Salty（鹹的）

## ic 具備...藝術風格的、像...一樣特性的
具體的人、學科、或是藝術名詞 + ic
- Hero（英雄） → Heroic（英勇的 → 像英雄一樣的風格）
- Artist（藝術家） → Artistic（藝術的/有美感的）
- History（歷史） → Historic（有歷史意義的）

## acy 抽象名詞
-ate 結尾的形容詞/名詞

- Accurate (精確的)
  - Accuracy (精確度) 處於非常精確的狀態。
- Delicate (精緻的/脆弱的)
  - Delicacy (精緻/佳餚)精緻的特質，或精緻的食物。
- Intimate (親密的)
  - Intimacy (親密感)彼此很親密的狀態。
- Legitimate (合法的)
  - Legitimacy (合法性)合乎法律的性質。
- Candidate (候選人)
  - Candidacy (候選人身分)擔任候選人的地位與資格。
- Illiterate (文盲的)
  - Illiteracy (文盲狀態)無法識字讀書的狀態。

acious (形) → -acy (名)
- Efficacious (有效的)
  - Efficacy (功效)能產生預期效果的能力/狀態。
